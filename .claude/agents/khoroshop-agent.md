# khoroshop-agent

## ПРИНЦИП ВЕРИФІКАЦІЇ

> ⚠️ **Перш ніж стверджувати "це працює" / "цей маппінг правильний" / "ця ціна вірна"** — перевір це фактом, не логікою коду:
> - **Факт** = реальний тест (тест-імпорт 1 товару, реальний запит до API з відповіддю, реальний парсинг сторінки конкурента)
> - **НЕ факт** = "код виглядає консистентним", "так написано в документації", "за аналогією з іншим маркетплейсом"
> - Якщо перевірити самостійно неможливо (потрібен логін людини, оплата тощо) — чесно скажи це і попроси власника зробити останній крок, замість вигаданого висновку
> - **Реальний приклад:** `epicentr_cpa_rates` мала точний text-lookup без normalization — категорія "Кабелі та перехідники" (з XML) не співпадала з "Кабелі та конектори" (з БД), тому комісія мовчки не застосовувалась попри те що код "виглядав правильним"

## Спільний інструмент: BaseHttpScraper

`tools/epicentr_competitor_scraper.py` — базовий клас `BaseHttpScraper` можна адаптувати під парсинг конкурентів на Khoroshop. **НЕ копіюй логіку парсингу сліпо** — перевір структуру сторінки Khoroshop і Cloudflare-захист окремо (Rozetka вже підтверджено заблокована з серверного IP, Єпіцентр — ні; Khoroshop — не перевірявся; плюс age-gate на сайтах конкурентів у цій ніші потребує окремої обробки).

## Роль
Ти агент-чат для напрямку **Khoroshop** у дропшипінг-системі `affilate_aggent`. Магазин на платформі вже існує, весь асортимент від постачальника «Секс Опт» вже доданий. Твоя задача — донастроювати магазин: ціноутворення, SEO, категоризація, обробка замовлень, автоматизація оновлень.

## Зона відповідальності (поточна/майбутня)

### Файли що треба створити (автоматизація)
- `tools/khoroshop_xml_generator.py` — генератор фіду Секс Опт → Khoroshop XML (якщо потрібен)
- `tools/khoroshop_xml_checker.py` — валідатор перед завантаженням
- `agents/orders/khoroshop_order_agent.py` — обробка замовлень
- `agents/orders/khoroshop_github_sync.py` — push фіду → GitHub (якщо Khoroshop тягне XML)
- `shared/knowledge_base/khoroshop/` — вимоги платформи, API-довідники
- `shared/mcp_servers/khoroshop_mcp.py` — MCP (опціонально)

### БД (перевикористати існуючі або створити)
- `supplier_category_mapping` — додати рядки для khoroshop
- Або створити нову таблицю `khoroshop_categories`

### ENV-змінні (потрібно перевірити/додати до .env)

## Пріоритети донастроювання

Власник додасть конкретний список — поки орієнтир:

1. **Ціноутворення** — перевірити що ціни актуальні (РРЦ × (1+комісія))
2. **SEO** — назви, описи, ключові слова відповідно до вимог Khoroshop
3. **Фото** — перевірити що всі фото завантажились і відображаються
4. **Категорії** — правильний маппінг товарів по категоріях платформи
5. **Замовлення** — налаштувати автоматичну обробку замовлень (daemon або API polling)
6. **Оновлення наявності** — автосинхронізація з фідом постачальника

## Єпіцентр + Секс Опт (паралельний напрямок)

> ⚠️ Товари Секс Опт планується розміщувати також на Єпіцентрі.
> Для цього є **СТОП-категорії від постачальника** (точний список власник додасть окремо) — певні категорії заборонено розміщувати на Єпіцентрі, але не на Khoroshop.
> Деталі в `epicentr-agent.md` → секція "Секс Опт на Єпіцентрі".

## Відомі граблі

1. **Age-gate і cookie-wall** на сайтах конкурентів — Playwright без обробки гейту дає 0 результатів. Потрібен окремий R&D перед стартом скрейпінгу конкурентів.
2. **`.env`** — додавати нові ключі одразу в `.env.example`.
3. **Git race condition** — `watchdog.py` авто-комітить кожні 10 хв. Завжди `git pull --rebase`.
4. **Великі XML** — додати в `.gitignore` до першого commit.

## Конкурентний аналіз

Для пошуку конкурентів на khoroshop-сумісних сайтах — перевір спочатку чи є Cloudflare (відкрий `curl -I URL` з сервера). Якщо SSR без CF — використовуй `tools/epicentr_competitor_scraper.py` як шаблон (`BaseHttpScraper`). Якщо є age-gate/cookie-wall — потрібен окремий R&D з Playwright.
Деталі: `shared/knowledge_base/competitor_scraping.md`. Результати в `competitor_prices` (marketplace='khoroshop').

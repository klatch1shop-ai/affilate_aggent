# Єпіцентр — правила імпорту (з NotebookLM)

## Ліміти файлів
- XML через кабінет: 50MB
- XML через URL: необмежено (асинхронно)
- XLSX: 50MB, макс 10000 товарів

## Обов'язкові поля
- name lang="ua" ✅ обов'язково
- name lang="ru" — НЕ обов'язково
- description lang="ua" ✅ обов'язково  
- description lang="ru" — НЕ обов'язково
- price, vendor, country_of_origin ✅
- weight, width, height, length ✅ (у грамах/мм)
- Мінімум 1 фото (рекомендовано 3+)

## Фото
- Тільки JPEG (.jpg/.jpeg)
- http:// або https://
- Мінімум 500x500px
- Без вотермарків

## Категорії
- Тільки відкриті (зелені в кабінеті)
- Нові категорії — через менеджера
- 2874 Автосвітло — треба активувати!

## Імпорт по URL (пріоритет!)
- Дати менеджеру GitHub raw URL
- Оновлення 1 раз на добу (можна частіше — через менеджера)
- Немає ліміту розміру

## 🔑 КРИТИЧНО: Як активувати OMS API

**Крок 1:** `admin.epicentrm.com.ua` → Налаштування → Налаштування компанії → **Додаткові параметри**
→ Увімкнути **"Підключення до API по замовленням"**

**Крок 2:** Перейти на вкладку **API** в кабінеті → скопіювати або згенерувати API-ключ

Після цього OMS endpoints стають доступні з тим самим токеном з .env (`EPICENTR_TOKEN`).

## API Endpoints (Merchant API)

### PIM (Product Information Management) — вже працює ✅
```
GET  /v2/pim/categories         # 108 сторінок категорій (page, pages, items)
```

### OMS (Order Management System) — потребує активації в кабінеті
```
GET  /v2/oms/orders             # список замовлень
GET  /v2/oms/orders/{id}        # деталі замовлення
POST /v2/oms/orders/{id}/status # зміна статусу
POST /v2/oms/orders/{id}/ttn    # збереження ТТН
```

### Base URL
```
https://merchant-api.epicentrm.com.ua
Authorization: Bearer {EPICENTR_TOKEN}
```

## Схема переходів статусів замовлення (ВАЖЛИВО — послідовна!)

```
Нове → Підтверджено продавцем → Відправлено → Готове до видачі → Завершено
                                                                ↓
                                                           Скасовано (можливо на будь-якому етапі)
```

**⚠️ Заборонено пропускати статуси** — Єпіцентр поверне помилку!

## Логіка роботи з замовленнями (з KeepinCRM)

### Автопідтвердження
- Єпіцентр **приховує контакти клієнта** на статусі "Нове"
- Щоб отримати контакти: автоматично змінити статус "Нове" → "Підтверджено продавцем"
- Тільки після цього стають доступні: ім'я, телефон, адреса доставки

### Таймінг
- На підтвердження зі статусу "Нове": **2 години** в робочий час
- Максимальний час: **24 години**
- Якщо не підтверджено → замовлення автоскасовується

### ТТН
- Автоматично передається при зміні статусу на "Відправлено"
- Можна відправити вручну окремим запитом

## Зв'язка товарів (з KeepinCRM)

KeepinCRM зв'язує товари по одному з варіантів:
1. **По артикулу** (наш SKU)
2. **По назві**
3. **По ідентифікатору Prom** (prom_id)
4. **По ID Єпіцентру** (`epicentrk_item_id`)

Для XLSX імпорту: поле `epicentrk_item_id` = внутрішній ID товару в Єпіцентрі.

---

## Обмеження Єпіцентру (важливо знати)

- Синхронізація товарів через API — **не підтримується** Єпіцентром
- XML синхронізація — **нестандартний формат** (не працює)
- Додати товар через API в замовлення — **неможливо**
- Завантажити завершені замовлення — тільки через **XLS імпорт**
- Автооновлення залишків — через фід, але потрібні **їхні внутрішні артикули**

## Наш план — краще за KeepinCRM

### Переваги нашої системи:
1. **AI агенти** — автоматичне прийняття рішень (KeepinCRM тільки роутить)
2. **Власна БД** — повна аналітика, history цін, конкуренти
3. **Ollama на GPU** — локальні LLM моделі без оплати за токени
4. **MCP сервери** — стандартний інтерфейс для всіх інтеграцій
5. **Playwright** — автоматизація будь-яких дій в браузері
6. **Telegram Gateway** — /learn навчання агентів через чат

### Порядок реалізації:
1. ✅ Prom.ua — повністю готово
2. 🔄 Єпіцентр OMS — активувати API в кабінеті → реалізувати
3. ⏳ Нова Пошта API — ТТН, трекінг, автопідстановка адреси
4. ⏳ Розетка — після активації
5. ⏳ SMS сповіщення покупцям
6. ⏳ Monobank webhook — підтвердження оплати

## Нова Пошта API (наступний пріоритет)

KeepinCRM використовує НП API для:
- Автопідстановки даних отримувача при створенні ТТН
- Трекінгу посилок
- Знаходження відділень

```
API: https://api.novaposhta.ua/v2.0/json/
Метод: POST з JSON body
apiKey: з .env (NP_API_KEY)
```

Ключові методи:
```json
{"modelName": "TrackingDocument", "calledMethod": "getStatusDocuments"}
{"modelName": "Address", "calledMethod": "getWarehouses"}
{"modelName": "InternetDocument", "calledMethod": "save"}  # створити ТТН
```

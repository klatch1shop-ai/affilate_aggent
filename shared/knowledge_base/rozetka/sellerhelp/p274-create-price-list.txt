 Підготовка XML прайс-листа з товарами
 Останнє оновлення: 12.06.2026

 Щоб розмістити товари на маркетплейсі ви можете експортувати дані про товари з вашої системи у форматі XML. Ознайомтеся з вимогами до структури XML файлу з товарами 

 XML прайс-лист (фід) — це структурований формат даних, який містить всю інформацію про ваші товари: ціну, статус наявності, кількість залишків, назву позиції, текстовий опис, характеристики, категорію, id (ідентифікатор у системі) тощо. Створити XML прайс-лист ви можете одним з наступних способів:

 Експортувати з вашої системи (CMS, ERP тощо).

 Створити або адаптувати у сервісі Pricecreator.

 Експортувати з кабінету компанії Prom.ua .

 Зважайте, для того, щоб товар був опублікований на маркетплейсі, інформація про товари має відповідати вимогам до контенту (назва товару, зображення, опис та характеристики).

 1. Експорт товарів з вашого сайту (системи)

 Технічна розробка або налаштування, за допомогою якого формується експорт даних у форматі XML фіду з даними про товари. Зверніться до вашого ІТ фахівця, або до компанії, яка підтримує ваш сайт для консультації чи можливо експортувати дані з вашої системи в потрібному форматі.

 Переваги: 

 Пряма інтеграція — ви керуєте ціною та наявністю товарів у вашій системі й інформація буде актуалізуватися на ROZETKA автоматично щогодини.

 Більша частина інформації про товари у вас вже є (назва товару, фотографії, опис тощо).

 Ви працюєте з товарами у вашій системі, до якої звикли.

 Недоліки: 

 Можливо потрібно буде редагувати інформацію про товари відповідно до вимог ROZETKA.

 Необхідність технічних знань або кваліфікованого фахівця.

 Не всі системи можуть налаштувати експорт даних у потрібному форматі.

 2. Створення списку товарів за допомогою сервісу Pricecreator

 Pricecreator — це сервіс для створення та управління товарами, який адаптований для роботи з маркетплейсом ROZETKA, та надає можливість налаштувати структуру вашого каталогу товарів відповідно до структури сайту ROZETKA. Дізнатись більше про сервіс Pricecreator 

 Переваги: 

 Ви можете адаптувати інформацію про товари для маркетплейсу, не змінюючи дані у вашій системі.

 Ви можете побачити та заповнити для позиції всі доступні характеристики в обраній категорії товару на маркетплейсі ROZETKA.

 3. Експорт товарів з кабінету компанії на платформі Prom.ua

 Для продавців Prom.ua доступний додаток «Робота з Rozetka» , який надає можливість експортувати дані про товари в необхідному форматі. Для підключення додатка вам необхідно зареєструвати профіль продавця та використовувати логін та пароль від кабінету продавця на ROZETKA Маркетплейс. Дізнатись більше про експорт товарів з Prom для ROZETKA 

 Переваги: 

 Швидкий експорт товарів у 3 кроки.

 Структура даних експорту відповідає вимогам маркетплейсу ROZETKA.

 Робота на двох маркетплейсах одночасно.

 Недоліки: 

 Необхідність змінювати опис і фото товарів на Prom відповідно до вимог ROZETKA.

 Через різну структуру категорій на Prom і ROZETKA, необхідно самостійно додавати деякі параметри товару (характеристики).

 Перед тим як надіслати прайс-лист товарів для підключення до вашого профілю продавця, будь ласка, самостійно перевірте його на наявність помилок та внесіть необхідні зміни в товари (якщо це потрібно).

 Зверніть увагу! Ми не співпрацюємо зі сторонніми ресурсами (сервісами), які пропонують платні послуги створення списку товарів для маркетплейсу ROZETKA.

 Поширені запитання 
 Як дізнатися які помилки можуть бути в XML прайс-листі?

 — Перевірте ваш прайс-лист (фід) на наявність основних помилок за допомогою інструменту для перевірки XML . Дізнатися більше про перевірку XML прайс-листа 

 Які програми (сервіси) використовувати для роботи з XML прайс-листом?

 — Ви можете використовувати будь-які сервіси чи програми, які дозволяють вам сформувати XML фід (прайс-лист з товарами), відповідно до наших вимог. Також для наших партнерів доступний сервіс для роботи з товарами — Pricecreator, отримати доступ до якого ви можете у нашого співробітника, який допомагає вам з реєстрацією та початком продажів на маркетплейсі.

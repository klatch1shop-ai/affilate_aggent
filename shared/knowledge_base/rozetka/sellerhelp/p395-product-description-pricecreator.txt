 Опис товару в Pricecreator
 Останнє оновлення: 12.06.2026

 Опис товару — це текстовий блок, з якого покупець може отримати інформацію про товар. Російський опис товару необхідно передавати в тегу <description> — поле "Повний опис (UA/RU)" в Pricecreator. Український опис в тегу <description_ua> — поле "Повний опис (UA)" в Pricecreator . Якщо опис в Pricecreator вказаний лише російською мовою для україномовної версії сайту ROZETKA він буде перекладений автоматично під час модерації. 

 Вимоги до заповнення опису товару: 

 не вказувати посилання на сторонні ресурси, ціни, інформацію про додаткові послуги, зображення чи відео, контакти;
 максимально допустима кількість символів — 50 000; 
 для візуального оформлення використовувати HTML форматування.

 Редагування опису в одній картці товару 

 Для зміни або додавання опису в одній картці товару, скористайтесь пошуком товару за назвою\артикулом\ offer id або знайдіть товар на сторінці категорії. Перейдіть у товар, в полях "Повний опис (UA/RU)" або "Повний опис (UA)" натисніть "Редактор" й внесіть зміни в опис.

 Після внесення змін або додавання опису, збережіть зміни окремою кнопкою "Зберегти зміни".

 Додаткові інструменти для роботи з описом: 

 очистка контенту — очищення тексту від стилів, символів; 
 відновити з бази — відновлення опису до колишнього стану (до редагування), працює інструмент якщо не натискали "Зберегти"; 
 HTML редактор — редагування тексту за допомогою HTML розмітки. Докладно про допустимі HTML теги. 

 Масове редагування опису товарів

 Назва, вендор (виробник) і опис заблоковані для редагування через XML. Змінити ці поля можливо лише вручну або з Excel. 

 Змінити масово опис товарів можливо в розділі "Робота с параметрами" 
 у файлі Excel. Перейдіть до розділу "Робота з параметрами" → 
"Вивантажити", встановіть додаткове налаштування для вивантаження опису та вивантажте файл. 

 У файлі внесіть зміни в
 стовпці "Повний опис (UA/RU)" або "Повний опис (UA)", завантажте файл у розділі 
"Робота з параметрами" → "Завантажити". 

 Якщо непотрібно передавати опис на ROZETKA, вимкніть його на сторінці "Вивантаження в XML". Опис буде присутній в Pricecreator, але не буде передаватись в XML Pricecreator (для модерації на ROZETKA). Перейдіть в розділ "Вивантаження в XML" та приберіть відмітку в стовпці "Всі описи" й тег <description> буде прибраний з XML Pricecreator.

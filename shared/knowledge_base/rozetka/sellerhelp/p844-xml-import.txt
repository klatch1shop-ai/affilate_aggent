 Додавання нових товарів через XML прайс-лист
 Останнє оновлення: 12.06.2026

 Якщо інформація про ваші товари імпортується через XML прайс-лист (фід), який підключений до вашого облікового запису продавця на маркетплейсі, в такому випадку ви керуєте товарами власній системі (власний сайт, сервіс Priceсreator, кабінет компанії на Prom тощо), тому створювати нові позиції необхідно саме у вашій системі.
 Щоб додати нові товари через XML прайс лист (фід): 

 Додайте нові позиції в XML прайс-лист, який підключений до вашого магазину на ROZETKA.

 Дочекайтеся синхронізації даних (протягом години), або здійсніть ручну синхронізацію, щоб нові позиції з’явилися в кабінеті продавця в розділі «Товари» → «Нові» .

 Відправте нові товари на модерацію. Виберіть потрібний товар(-и) та натисніть кнопку « Відправити на модерацію ». Для даних позицій буде створена заявка на модерацію і вони відображатимуться в розділі «Товари» → «На модерації» . Зображення для нових товарів будуть завантажені під час модерації.

 В кабінеті продавця ви можете налаштувати для прайс-листа автоматичне відправлення нових товарів на модерацію .

 Після додавання нових товарів у XML файл, рекомендуємо вам самостійно зробити перевірку XML прайс-листа на наявність помилок.

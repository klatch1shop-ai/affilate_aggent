 Green API
 Останнє оновлення: 12.06.2026

 Green API — це сервіс, який надає доступ до унікальних даних ROZETKA. Наразі в Green API ви можете отримати доступ до інструменту «Показник викупу замовлень» — це інформація, яка формується на основі історії покупок та активності користувача на маркетплейсі ROZETKA.

 Як під'єднати Green API

 В кабінеті продавця перейдіть в розділ «Green API» та натисніть кнопку «Підключити».

 Введіть ваш e-mail та пароль, який ви будете надалі використовувати для авторизації у сервісі Green API, та натисніть «Підключити».

 Оберіть тариф для користування сервісом. Наразі доступний лише безкоштовний тариф «Базовий».

 Показник викупу замовлень

 Щоб отримати інформацію про покупця, в розділ «Green API» → «Показник викупу замовлень» введіть номер телефону у пошукове поле та натисніть «Перевірити». Ви отримаєте інформацію про:

 кількість позитивних/негативних оцінок продавців;

 відсоток викупу замовлень;

 кількість відмов від посилки;

 кількість посилок, які не забрали (за якими не прийшли у відділення);

 коментарі від інших продавців.

 Відсоток викупу замовлень в Green API розраховується на основі історії замовлень на ROZETKA протягом останніх 3 роки, в яких цей номер телефону був вказаний як отримувач замовлення , і якщо їх кількість перевищує 3.

 Кількість відмов від посилки та кількість посилок, які не забрали — це показники, що рахуються на основі відгуків продавців про досвід взаємодії із покупцем. Якщо дані показники відсутні, а відсоток викупу низький — це значить, що жоден продавець ще не залишив відповідний відгук про користувача.

 Щоб залишити власний відгук про покупця, натисніть «Додати коментар», вкажіть вашу оцінку та опишіть досвід в коментарі.

 Оцінки та відгуки, які ви будете залишати, мають відображати реальний досвід співпраці з покупцем та не містити неправдиву інформацію про нього, чи будь-які персональні дані. У разі виявлення порушень, ми будемо змушені призупинити доступ вашого облікового запису до використання сервісу Green API.

 Зверніть увагу! Green API не проводить ідентифікацію конкретної особи за номером телефону, а лише надає інформацію про історію та досвід, пов'язаний із замовленнями за цим номером.

 Якщо вам потрібно отримати API токен до сервісу Green API (для інтеграції з вашою системою), зверніться в службу підтримки за темою «Акаунт, особистий кабінет, API» → «Питання по API» та надайте адресу електронної, яку ви вказали при підключенні до сервісу.

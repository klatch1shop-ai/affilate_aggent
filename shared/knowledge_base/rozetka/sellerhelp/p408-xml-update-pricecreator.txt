 Правила роботи з файлом XML:
 формат файлу XML (YML), вимоги до XML ;

 url-адреса на xml прайс-лист має бути доступною для роботи в Pricecreator. Якщо на сервері встановлено обмеження, внесіть на сайт виключення для таких ip-адрес: 135.181.1.154 | 138.201.237.86 | 135.181.168.123

 не змінювати id товарів та категорій;

 символи ", &, > <, ' потрібно замінювати еквівалентними кодами. *Вимога стосується лише написання тексту і не стосується написання тегів;

 Оновлення товарів з XML в Pricecreator
 Підготуйте файл XML для оновлення, перейдіть в розділ "Імпорт" → "Оновити статус, ціну та кількість". В цьому розділі оновлюється лише ціна, наявність та залишки.
 У рядку оновлення оберіть файл, якщо він доступний в списку, якщо файл новий вставте його в "Вставити посилання" та натисніть "Оновити". 
 Після обробки файл, буде доступна ієрархія категорій за файлу та кількість товару. Для оновлення всього файлу натисніть "Оновити всі" або на окрему категорію, якщо потрібно оновити конкретні товари, дочекайтеся звіт оновлення.
 Автооновлення товарів з XML
 Автооновлення — автоматичне оновлення ціни, наявності та залишків у Pricecreator із джерела XML. Оновлюється, ціна, наявність та кількість, нові товари автоматично не додаються. Товари оновлюються, якщо в них присутній "Оригінальний id" та товар прив'язаний до посилання, якщо в товарі ця інформація відсутня — його потрібно налаштувати.  
 Стандартне автоматичне налаштування оновлення:
 оновлення товарів в Pricecreator раз на годину;

 для оновлення наявності, товар повинен бути присутнім в посиланні зі статусом available "false" або stock_quantity = 0. Якщо в посиланні товар відсутній — наявність змінена не буде.

 Щоб увімкнути автоматичну синхронізацію з джерела, перейдіть до розділу "Імпорт товарів"→ "XML"→ "Автооновлення" та поставте позначку навпроти джерела.
 У розділі доступне посилання з останнього імпорту. Для зміни посилання потрібно зробити імпорт з новим посиланням. 
 Для оновлення в конкретний проміжок часу або ігнорування окремих тегів, призначати "Немає в наявності" товарам, яких немає в посилання, встановіть додаткові налаштування: 
 час запуску — проміжок часу коли буде оновлення в Pricecreator; 

 відсутні — товар, якого немає в посиланні, але він присутній в кабінеті, буде призначено статус "Немає в наявності"; 

 ігнорувати — поля, які будуть ігноруватись під час оновлення.

 Додатково можливо налаштувати ціну, яка буде використовуватись в товарах цього джерела. Товари, які додані з цього джерела, будуть використовувати ціну, яка обрана в цьому розділі (окремо від налаштувань кабінету): 
 Системне налаштування —  налаштування одного типу ціни для всіх товарів в кабінеті, без прив'язки до джерела.

 Оригінальна ціна — в товарах цього джерела буде використовуватися поле "Оригінальна ціна". 

 Ціна — в товарах цього джерела буде використовуватися поле "Ціна".

 Налаштування товарів для автоматичного оновлення
 Товари оновлюються, якщо в них присутній "Оригінальний id" та товар прив'язаний до посилання, якщо в товарі ця інформація відсутня — його потрібно налаштувати. 
 Призначити оригінальний id, присутньому товару в кабінеті, можливо лише через Excel. Вивантажте файл з товарами в розділі "Робота з параметрами" → "Вивантажити". У вивантаженому файлі заповніть стовпець "OFFER ID", наприклад перенесіть значення зі стовпчика "ID". Завантажте файл у розділі "Робота з параметрами" → "Завантажити". Товару буде призначено "Оригінальний id". У своїй системі обліку товарів (звідки буде оновлення товарів) вкажіть той самий код товару. 
 Призначення нового оригінального id призведе до зміни offer id в XML Pricecreator. Якщо товари вже активні на ROZETKA — зміна offer id забороняється. Рекомендуємо призначати код (offer id), який вже використовується на ROZETKA.
 Для прив'язки товару до посилання XML проведіть імпорт посилання в "Імпорт товарів" →"XML"→ "Імпорт". Якщо в товарі "Оригінальний id" збігається з offer id в XML — посилання успішно прив'яжеться й надалі можливо буде увімкнути автоматичне оновлення.

 Зміна юридичних даних
 Останнє оновлення: 12.06.2026

 Власником облікового запису продавця на маркетплейсі є ФОП / юридична особа або фізична особа, яка прийняла умови публічної оферти та надала необхідні для реєстрації документи. У разі зміни юридичних даних, вам потрібно повідомити про це завчасно, або протягом 3-х днів з моменту набрання чинності відповідних змін. Якщо ви не повідомите про зміну юридичної інформації, або якщо ваша юридична особа / ФОП знаходиться в процесі припинення своєї діяльності — магазин буде заблоковано . Якщо ви бажаєте змінити власника облікового запису, скористайтесь іншою інструкцією 

 Щоб повідомити про зміну юридичних даних: 

 Завантажте та заповніть шаблон листа про зміну реквізитів :

 вкажіть дату на номер документа;

 вкажіть дату, з якої зміни набрали/набирають чинність;

 в шаблоні листа залиште лише те, що змінюється, та видаліть зайве з переліку та списку додатків.

 Напишіть лист на електронну пошту du@rozetka.com.ua . В темі вкажіть "Зміна юридичних даних — назва магазину на маркетплейсі", в листі коротко опишіть що змінилося, прикріпіть заповнений шаблон та кольорові фото/скан копії нових документів, що підтверджують зміну юридичних даних.

 Залежно від того, що необхідно змінити, вам потрібно надати наступні документи: 

 для зміни найменування юридичної особи — виписка, статут, опис;

 для зміни прізвища / ім'я / по батькові ФОП — паспорт, виписка;

 для зміни директора (виконавчого органу юридичної особи) — наказ/протокол про призначення директора;

 для зміни особи, уповноваженої підписувати документи з ТОВ «ТЕРМІНАЛ РОЗЕТКА» — довіреність;

 для зміни реквізитів банківського розрахункового рахунку — довідка про відкриття рахунку в банку;

 для зміни юридичної адреси — виписка з ЄДРПОУ (для ФОП також сторінка паспорта з новим місцем реєстрації).

 Щоб змінити адресу для листування, номер телефону, адресу електронної пошти, логін власника магазину, або якщо у вас змінилася група ФОП — документи додавати не потрібно.

 Для актуалізації документів, співробітник маркетплейсу може додатково запросити довідку з банку про відкриття розрахункового рахунку, дата видачі якої має бути не пізніше 1 року до поточної дати звернення.

 Зверніть увагу! Лист для зміни юридичних реквізитів необхідно відправляти з e-mail адреси, яку ви вказували для документообігу при реєстрації на маркетплейсі, інакше звернення буде відхилено.

 Б/В і Refurbished товар у Pricecreator
 Останнє оновлення: 12.06.2026

 Вимоги для продажу вжитого (Б/В) або відновленого (Refurbished) товару:

 в кінці назви товару вказати "Б/В" або "Refurbished";
 в описі необхідно перерахувати всі дефекти та особливості даного вживаного товару;
 у зображенні товару потрібно додати фото безпосереднього того продукту, який був у використанні і який отримає покупець (живі фото).
 Докладно про вимоги ROZETKA до заповнення товару. 

 Вказати стан товару в одній картці товару 

 Для зміни або додавання стану товару, скористайтесь  пошуком товару за назвою\артикулом\ offer id або знайдіть товар на сторінці категорії. Активуйте чекбокс «Товар Б/в» — це відкриє додаткові поля для заповнення. 

 Виберіть стан товару. У випадаючому списку ви знайдете такі варіанти: "Б/В" "Уцінка" "Відновлений" 

 Заповніть поле "Причина уцінки" Це поле є обов'язковим і використовується для вказання причини уцінки товару.

 Масове оновлення поля «Причина уцінки» через Excel

 Перейдіть до розділу «Робота з параметрами». У меню кабінету виберіть « Робота з параметрами », а потім натисніть «Вивантажити» Виберіть необхідні поля для експорту. На сторінці « Вивантажити товари з параметрами » у списку доступних опцій відзначте галочкою «Поля уцінки» 

 Натисніть кнопку «Скачати (spreadsheet)» , щоб отримати файл Excel. Відредагуйте дані у файлі 

 У колонках «Причина уцінки» та «Причина уцінки (укр)» вкажіть необхідний текст. Завантажте оновлений файл назад через " Вивантажити товари з параметрами " → " Завантажити" 

 Вказати стан товару масово з XML

 Вкажіть стан товару у своїй системі обліку товарів, згенеруйте XML 
файл та проведіть імпорт в Pricecreator. Проведіть імпорт у розділі 
"XML" → "Імпорт" та дані будуть змінені в кабінеті Pricecreator.

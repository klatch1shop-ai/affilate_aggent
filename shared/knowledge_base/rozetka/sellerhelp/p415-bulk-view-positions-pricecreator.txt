 Масовий перегляд позицій в Pricecreator
 Останнє оновлення: 12.06.2026

 Масовий перегляд позицій — це розділ де доступні всі товари на одній сторінці й часткове редагування товару (зміна категорії, зміна джерела, видалення товару тощо). Розділ знаходиться на головній сторінці кабінету, в блоці "Деталізація помилок".

 Перейдіть в розділ "Перегляд позицій", на сторінці можливо встановити фільтрація (товар без ціни, без зображень, без налаштованої категорії ROZETKA), скористатись пошуком або обрати категорію чи джерело, з якого були додані товари, сортувати за датою додавання та в XML товар чи ні. 

 Редагування товару у розділі 

 Після фільтрації можливо в обраних товарах змінити категорію або джерело, перенести товар в XML або вимкнути опис. 

 Для зміни категорії, оберіть окремі товари або одразу всі товари, у рядку "Змінити категорію" виберіть нову категорію та натисніть "Застосувати", товари будуть переміщені в нову категорію. 

 Для зміни джерела встановіть сортування за джерелом, оберіть окремі товари або одразу всі товари, в рядку "Змінити джерело" виберіть нове джерело для призначення та натисніть "Застосувати".

 Для переміщення товару в XML або для вимкнення опису, оберіть окремі товари або одразу всі товари, в рядку "Дії в XML" оберіть потрібні дії. 
 Для видалення товару, в кінці рядка натисніть на значок видалення й товар буде переміщено у кошик.

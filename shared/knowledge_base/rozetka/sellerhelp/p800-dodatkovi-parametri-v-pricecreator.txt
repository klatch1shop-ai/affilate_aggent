 Додаткові характеристики в Pricecreator
 Останнє оновлення: 12.06.2026

 Додаткова інформація про товар, яка впливає на замовлення або відображення товарів на ROZETKA. 

 Кількість товарів в замовленні Pricecreator Параметр "Доставка\оплата" Товари на замовлення (Передзамовлення) 

 Кількість товарів в замовленні Pricecreator

 Мінімальна ( min_cart_quantity ) або максимальна ( max_cart_quantity ) кількість товару в замовленні — це кількість товару, яке може замовити покупець на сайті ROZETKA. Покупець не зможе оформити замовлення на меншу чи більшу кількість товару, ніж встановлена продавцем. Додатково необхідно написати попередження в характеристиці "Доставка/оплата". Приклад: у картці товару можливо замовити від 3 штук.

 Для додавання мінімально\максимальної кількості в кабінеті Pricecreator скористайтесь пошуком товару за назвою\offer id\артикулом або знайдіть товар на сторінці категорії. Перейдіть до нього та внесіть значення у поля "Мінімальна кількість на замовлення" або "Максимальна кількість на замовлення". 

 Для додавання мінімально\максимальної кількості масово через Excel, вивантажте файл з товарами в одному з розділів " Робота з параметрами " → "Вивантажити" або "Імпорт зовнішнього Excel" → " Оновлення статусу, ціни та кількості з Excel ". У вивантаженому файлі заповніть стовпець "Мінімальна кількість на замовлення" або "Максимальна кількість на замовлення" завантажте файл у розділі, з якого вивантажували товари. 

 Додайте тег мінімально\максимальної кількості у своїй системі обліку товарів, згенеруйте XML файл та проведіть імпорт у Pricecreator. Провести імпорт у розділі "XML" → " Імпорт ". Приклад тегів у XML для імпорту: 

 <offer id="52" available="true"> .. <min_cart_quantity>3</min_cart_quartity> або <max_cart_quantity>5</max_cart_quartity> 
 <param name="Доставка/Оплата">Мінімальна кількість у замовленні від 3 шт. </param> ... </offer> 

 Заповнення характеристики "Доставка/оплата" в Pricecreator

 Вказати додаткові умови, терміни доставки товару чи оплати потрібно в параметрі "Доставка/оплата", наприклад, якщо товар під замовлення , термін доставки більше 2-х днів, безкоштовна доставка при замовленні на певну суму тощо.

 Для додавання параметра в одній картці товару, в кабінеті Pricecreator скористайтесь пошуком товару за назвою\offer id\артикулом або знайдіть товар на сторінці категорії. Перейдіть до нього, під описом відкрийте стовпчик "Доступні характеристики ROZETKA" та внесіть додаткові умови в параметр "Доставка/оплата". 

 Для додавання параметра масово через Excel, вивантажте файл з товарами в одному з розділів " Робота з параметрами " → "Вивантажити". У вивантаженому файлі заповніть стовпець "Доставка/оплата" та завантажте файл у розділі, з якого вивантажували товари. 

 Для додавання параметра з XML, актуалізуйте параметр у своїй системі обліку товарів, згенеруйте XML файл та проведіть імпорт XML в Pricecreator. Приклад параметра в XML:

 <param name="Доставка/Оплата"> <value lang="uk">Відправляємо за умови передоплати 20%</value> <value lang="ru">Отправляем при предоплате 20%</value> </param> 

 Проведіть імпорт у розділі "XML" → " Імпорт ", параметри будуть додані "Характеристики продавця", після імпортування їх потрібно порівняти зі списком "Доступні характеристики ROZETKA". 

 Товари на замовлення (Передзамовлення)

 Товари на замовлення — якщо для виготовлення/постачання товару продавцю знадобиться понад 7 календарних днів, можливо вказати цю інформацію в товарі й додати відповідну кнопку на сайті ROZETKA, замість кнопки «Купити» відображається кнопка «Передзамовити». 

 Для підключення даної кнопки на ROZETKA, в Pricecreator потрібно додати відповідні параметри, "Кнопка передзамовлення" — "Передзамовити" і "Термін доставки" — "7". Додаткові умови продажу товару потрібно вказувати в параметрі "Доставка/оплата" . Для додавання параметра в одній картці товару, в кабінеті Pricecreator скористайтесь пошуком товару за назвою\offer id\артикулом або знайдіть товар на сторінці категорії. Перейдіть до нього, під описом відкрийте стовпчик "Доступні характеристики ROZETKA" та заповніть відповідні параметри. 

 Для додавання параметрів масово через Excel, вивантажте файл з товарами в одному з розділів " Робота з параметрами "→ "Вивантажити". У вивантаженому файлі заповніть потрібні стовпчики та завантажте файл у розділі, з якого вивантажували товари.  

 Для додавання параметрів з XML, актуалізуйте параметри у своїй системі обліку товарів, згенеруйте XML файл та проведіть імпорт XML в Pricecreator. Приклад параметрів в XML:

 <param name="Кнопка передзамовлення">Передзамовити </param> <param name="Термін доставки">7 </param> 
 <param name="Доставка/Оплата"> <value lang="uk">Термін доставки замовлення 7 днів</value> <value lang="ru">Срок доставки заказа 7 дней</value> </param> 

 Проведіть імпорт у розділі "XML" → " Імпорт ", параметри будуть додані "Характеристики продавця", після імпортування їх потрібно порівняти зі списком "Доступні характеристики ROZETKA".

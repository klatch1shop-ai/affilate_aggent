 ID товарів в Pricecreator
 Останнє оновлення: 15.06.2026

 У Pricecreator присутні два види ID:
 Внутрішній ID   — призначається системою автоматично, при створенні товарів вручну або через Excel. Використовується як offer id в XML Pricecreator (якщо відсутній оригінальний id);

 Оригінальний id — передається з імпортом XML або призначається вручну з Excel, виступає ідентифікатор в системі для оновлення з файлу XML . 

 Якщо в товарі відсутній "Оригінальний id", налаштувати автооновлення зі стороннього XML неможливо. 
 Для автооновлення товарів з XML потрібно призначити товарам "Оригінальний id", а після налаштовувати оновлення з XML в Pricecreator. 
 Призначити оригінальний id товару в Pricecreator
 Призначення нового оригінального id призведе до зміни offer id в XML Pricecreator. Якщо товари вже активні на ROZETKA — зміна offer id забороняється. Рекомендуємо призначати код (offer id) у своїй системі, який вже використовується на ROZETKA, для налаштування синхронізації. 
 Призначити оригінальний id присутньому товару в кабінеті можливо лише через Excel. Вивантажте файл з товарами в розділі " Робота з параметрами " → "Вивантажити". У вивантаженому файлі заповніть стовпець "OFFER ID", наприклад перенесіть значення зі стовпчика "ID". Завантажте файл у розділі "Робота з параметрами" → "Завантажити". Товару буде призначено "Оригінальний id".

 Покрокова інструкція додавання товару в Pricecreator
 Останнє оновлення: 01.07.2026

 У кожному способі додавання товарів дотримуйтесь послідовність кроків.

 Ручне додавання товарів в кабінет Pricecreator 

 Створити категорію —
 створити категорію в якій буде розміщуватися товар.

 Додати картку товару. 

 Вивантажити товари в
 XML — перенести товари в посилання XML і відправити сформований файл в службу підтримки продавця для
 активації товарів на сайті ROZETKA.

 Додавання товарів за допомогою Excel

 Умови імпорту Excel: 

 забороняється змінювати структуру файлу, встановлювати фільтри, додавати\видаляти стовпці, об'єднувати сторінки;

 артикул та назва повинні бути унікальні;

 обов'язкові поля в для заповнення: категорія, назва, ціна, статус (в наявності \ немає в наявності).

 Послідовність кроків: 

 Створити категорію — для
 вивантаження шаблону Excel з категоріями та параметрами. 

 Вивантаження/завантаження
 шаблону Excel. 

 Оновити зв'язок —
 закріплення категорії ROZETKA в нових товарів.

 Порівняти
 параметри  — порівняння параметрів в картці товару, в стовпцях "Характеристики продавця" і "Доступні
 характеристики ROZETKA".

 Вивантажити товари в
 XML — перенести товари в посилання XML і відправити сформований файл в службу підтримки продавця для
 активації товарів на сайті ROZETKA.

 Додавання товарів за допомогою XML (YML)

 Умови використання файлу XML: 

 формат файлу XML (YML), вимоги
 до XML ;

 url-адреса на xml прайс-лист має бути доступною для роботи в Pricecreator. Якщо на сервері встановлено
 обмеження, внесіть у виключення такі ip-адреси: 135.181.1.154 | 138.201.237.86 | 135.181.168.123

 не змінювати id товарів та категорій;

 символи ", &, > <, ' потрібно замінювати еквівалентними кодами. *Вимога стосується лише написання тексту і
 не стосується написання тегів;

 Обмеження ваги локально файлу XML 50 Мб.

 Послідовність кроків: 

 Імпорт XML — додавання
 товарів за допомогою XML файлу.

 Налаштування
 категорій — налаштування категорій ROZETKA у нових товарах. 

 Порівняти
 параметри — порівняння параметрів в картці товару, в стовпцях
 "Характеристики продавця" і "Доступні характеристики ROZETKA".

 Вивантажити товари в
 XML — перенести товари в посилання XML і відправити сформований файл в службу підтримки продавця для
 активації товарів на сайті ROZETKA.

 Модуль Нова Пошта
 Останнє оновлення: 12.06.2026
 Зробити це через API 

 Модуль надає можливість створювати відправлення (ТТН) для замовлення, в якому покупець обрав доставку перевізником Нова Пошта, та відстежувати статус відправлення безпосередньо в кабінеті продавця.

 Підключення та активація

 Зареєструйтесь на сайті перевізника Нова Пошта та згенеруйте API ключ для вашого облікового запису (розділ «Налаштування»).

 В кабінеті продавця в налаштуваннях модуля введіть отриманий API ключ і натисніть кнопку «Зберегти».

 За необхідності змінити ключ API натисніть на значок редагування поруч із зазначеним ключем, введіть нове значення та збережіть зміни. За вказаним API ключем у вкладці «Список ТТН» відображається історія створених відправлень.

 Зверніть увагу! При зміні особистих даних облікового запису в кабінеті Нової Пошти, необхідно оновити ключ API в налаштуваннях модуля в кабінеті продавця, інакше історія відправлень не буде оновлюватися автоматично.

 Створення відправлення Нова Пошта

 Зверніть увагу! До 31.12.2025 діють акційні умови для доставки у поштомати Нова Пошта. Ознайомитись детальніше ви можете за посиланням .

 В модулі перейдіть до вкладки «Створення ТТН» або натисніть кнопку «Створити ТТН» в замовленні зі статусом «Комплектується. Дані підтверджені».

 Заповніть інформацію в блоці відправника та одержувача. Для доставки кур’єром Нової Пошти заповніть повну адресу отримувача.

 Вкажіть параметри відправлення: тип, вага, кількість, висота, ширина, довжина, оголошена вартість, опис, номер замовлення та назву товару.

 Виберіть спосіб оплати та вкажіть платника і суму зворотної доставки грошей (якщо це післяплата).

 За потреби виберіть додаткові послуги:

 Контроль оплати — передбачає що оплата за товар буде перерахована на ваш розрахунковий рахунок в банку (послуга доступна тільки для бізнес-клієнтів Нової Пошти, у яких підписаний відповідний договір).

 Натисніть «Створити ТТН».

 Створені відправлення відображаються у вкладці «Список ТТН» з актуальним статусом від перевізника. За потреби ви можете завантажити маркування для посилки у форматі .pdf та надрукувати її.

 Друк маркування (ТТН) Нова Пошта

 У вкладці «Список ТТН» виберіть одну або кілька накладних, після чого з’явиться іконка для друку, натисніть на неї та виберіть формат для друку: експрес накладна або маркування 100х100 типу «Зебра».

 Налаштування модуля Нова Пошта

 В налаштуваннях модуля ви можете:

 Вказати API ключ до вашого облікового запису в кабінеті Нова Пошта.

 Заповнити інформацію про відправника та параметри відправлення, яка буде автоматично заповнюватись при створенні нового відправлення.

 Налаштувати додаткові параметри:

 чи передавати вартість замовлення в оголошену вартість посилки;

 чи передавати список товарів в додаткову інформацію про посилку;

 увімкнути/вимкнути послугу «Контроль оплати».

 Встановити тариф для комісії за грошовий переказ. Ця вартість відображається на сторінці оформлення замовлення та сплачується покупцем при отриманні посилки у перевізника. 
 За замовчуванням встановлено – 2% + 20 грн (стандартний тариф). Якщо ви відправляєте замовлення з послугою «Контроль оплати» та самостійно сплачуєте за послуги NovaPay, тоді рекомендуємо встановити тариф 0% + 0 грн. Якщо в списку немає потрібного вам тарифу, зверніться в службу підтримки за темою «Оплата і доставка замовлень» → «Додати/редагувати способи доставки і оплати» з проханням додати ваш тариф.

 Поширені запитання 
 Як створити відправлення в поштомат Нової Пошти?

 Створюючи відправлення в модулі Нова Пошта, в блоці отримувача знайдіть потрібний поштомат за номером або адресою та оберіть його зі списку, що відкриється. Також ви можете створити відправлення в поштомат на сайті перевізника та додати номер експрес-накладної до замовлення, коли будете встановлювати йому статус «Передано до служби доставки».

 Як прибрати комісію за грошовий переказ, якщо продавець користується послугою «Контроль оплати» від Нова Пошта?

 Встановіть відповідний тариф в налаштуваннях модуля Нова Пошта.

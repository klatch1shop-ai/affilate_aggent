 Вивантаження товарів у XML Pricecreator
 Останнє оновлення: 01.07.2026

 Після додавання та налаштування товарів у Pricecreator, необхідно сформувати файл XML для додавання та керування
 товарами на ROZETKA. Переконайтеся, що інформація про товари відповідає вимогам до
 оформлення. Для формування товару у форматі XML, перейдіть в розділ "Вивантаження в XML", для зручності встановіть сортування списку або скористайтесь пошуком за назвою\ID.
 Для формування посилання потрібно товари перемістити в XML, напочатку рядка проставте позначки в стовпці "В
 XML" у всіх одразу або окремих товарах.

 Якщо товар не налаштований (без категорії ROZETKA, відсутні параметри або фотографії), перенести його в XML
 неможливо. Помилки, які можуть виникнути при переміщенні товару:

 мінімальна к-сть параметрів 2 — недостатньо параметрів, перейдіть в картку товару і заповніть " Доступні
 характеристики ROZETKA "; 

 мінімальна к-сть зображень 1 —  в товарі немає зображень. Перейдіть в картку товару і додайте зображення ;

 Відсутня ціна в товарі — якщо в товари відсутня ціна, в XML цей товар буде відсутній. 

 XML Pricecreator заблокований для перегляду та для використання на сторонніх ресурсах.
 Вивантажити товари з Pricecreator можливо лише у форматі "Excel".

 Скопіюйте посилання на головній сторінці кабінету натиснувши "Скопіювати лінк у буфер" та надайте посилання менеджеру
 ROZETKA для перевірки або налаштування синхронізації. 

 Перевірити посилання та товари можливо за допомогою " Валідатор прайс-листів XML ", додатково
 переглянути товари можливо в Pricecreator в розділі "Перегляд XML". В розділі "Імпорт" → "XML" → "Перегляд XML"
 в рядок посилання вставте скопійоване посилання XML Pricecreator й натисніть читати, внизу показуватимуться
 товари з посилання.

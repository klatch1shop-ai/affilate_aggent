# Prom.ua API та XML FAQ
# Джерело: NotebookLM, 2026-06-09

## Формати прайсу
XLS/XLSX, CSV, XML/YML
Найкращий для автооновлення: XML/YML

## Обов'язкові поля XML
id, available, name, categoryId, portal_category_id, price, selling_type
name_ua і description_ua — тільки разом або жодного

## portal_category_id
Аналог rz_id. Тільки кінцева категорія! Батьківська = критична помилка.
Список: Кабінет → Імпорт → Список категорій

## Фото
До 10 шт. JPG/GIF/PNG. URL через кому з пробілом. Оптимально 1280x1280.

## Назва
Макс 110 символів. Не ALL CAPS. Без акція/знижка/телефонів.

## Оновлення по посиланню
Ціни/наявність: кожні 4 год (07-22)
Повне: раз на добу (вночі)
Недоступний 6 днів = автооновлення вимикається

## API
POST /products/edit_by_external_id — оновлення до 100 товарів
GET /orders/list — замовлення (polling 15-30 хв, webhook немає)
POST /orders/set_status — зміна статусу
POST /delivery/save_declaration_id — ТТН

## Статуси
new | accepted | paid | delivered | canceled

## TecDoc
type="vendor.model", vendor + model обов'язкові
Китай: vendor="Без бренда", кросс-номери замість коду

## Ручна сумісність
Сумісність з маркою: Volkswagen | Skoda
Сумісність з моделлю: Golf | Octavia
Рік випуску: 2018 | 2019 | 2020

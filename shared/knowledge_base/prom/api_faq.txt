# Prom.ua API та XML FAQ
# Джерело: NotebookLM аналіз документації, 2026-06-09

## Формати прайсу
Підтримуються: XLS/XLSX, CSV, XML/YML
Найкращий для автооновлення: XML/YML

## Обов'язкові поля XML
- id (унікальний)
- available (true/false)
- name (назва)
- categoryId (внутрішній ID групи продавця)
- portal_category_id (ID категорії Prom — НАЙВИЩИЙ ПРІОРИТЕТ, тільки кінцева категорія!)
- price (якщо available=true)
- selling_type (retail/wholesale/service)
- name_ua і description_ua — обидва разом або жодного

## portal_category_id
- Аналог rz_id Розетки
- Тільки числовий ID кінцевої (термінальної) категорії
- Батьківська категорія = критична помилка
- Завантажити список: Кабінет → Імпорт → Список категорій (XLSX/XML)

## Фото
- До 10 фото на товар
- Формати: JPG, GIF, PNG
- Макс: 10 МБ (15 МБ по URL)
- Оптимально: 1280x1280 px
- Кілька URL через кому з пробілом

## vendor
- Обов'язковий при type="vendor.model"
- Обов'язковий для автозапчастин (TecDoc)
- Якщо невідомий — "Без бренда"

## Назва товару
- Макс: 110 символів (UA: 130)
- Не ALL CAPS
- Без рекламних слів (акція, знижка)
- Без телефонів і посилань
- Мінімум одна літера алфавіту

## Оновлення по посиланню
- Ціни/наявність: кожні 4 години (07:00-22:00)
- Повне оновлення: раз на добу (вночі)
- Якщо файл недоступний 6 днів — автооновлення вимикається

## API оновлення наявності
POST /products/edit_by_external_id
Body: [{"external_id": "sku-123", "price": 550, "presence": "available"}]
presence: available | not_available | order | service
Ліміт: 100 товарів на запит

## Замовлення API
GET /orders/list
GET /orders/{id}
Polling кожні 15-30 хв (webhook немає!)

## Статуси замовлень
new | accepted | paid | delivered | canceled
GET /order_status_options/list — повний список

## Зміна статусу
POST /orders/set_status
Body: {"status": "accepted", "ids": [123]}

## ТТН
POST /delivery/save_declaration_id
Body: {"order_id": 123, "declaration_id": "20451458370815"}

## TecDoc (автозапчастини)
type="vendor.model" → vendor + model
Час появи: до 24 годин
Китайські аналоги: vendor="Без бренда", код порожній, кросс-номери

## Ручна сумісність (не в TecDoc)
Характеристики через | з пробілами:
- Сумісність з маркою: Volkswagen | Skoda
- Сумісність з моделлю: Golf | Octavia
- Рік випуску: 2018 | 2019 | 2020

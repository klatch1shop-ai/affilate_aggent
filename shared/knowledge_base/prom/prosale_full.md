## 1. ДОСТУП ТА ПРОСУВАННЯ У КАТАЛОЗІ PROSALE
URL: https://support.prom.ua/hc/uk/articles/360004966437

### Що таке ProSale:
- Інструмент для відображення та просування товарів на Prom
- CPA (за замовлення через кошик) або CPC (за перехід/телефон)
- Покази НЕ оплачуються — тільки цільові дії

### Де відображаються товари:
- Видача за категоріями, тегами, результати пошуку
- Сторінка компанії у каталозі
- Блоки: "Ви переглядали", "Ми рекомендуємо", "Мегазнижки"
- "Подібні товари", "Супутні товари", "З цим також замовляють"
- Партнерські CPA мережі, тизерні мережі
- Пошукові системи (Google), соціальні мережі
- Сайти динамічного ретаргетингу

### Типи видачі:
1. Пошукова — результати пошуку в каталозі
2. Тегова — перехід з пошукової системи в каталог
3. Видача в категорії — при переході через меню

### Від чого залежить частота відображення:
- Популярність товару
- Якість заповнення картки
- Рейтинг товарів
- Топ-продавці отримують додатковий пріоритет

### Вартість:
- Відповідає єдиній комісії за категоріями
- Однакова для всіх продавців у категорії
- Топ-продавці можуть увімкнути Турбо/Більше продажів

### Умови потрапляння в кампанію CPA (за замовлення):
- Замовляють через кошик
- Продаються в роздріб/оптом
- Статус "в наявності" або "під замовлення"
- Є ціна
- Є хоча б одне фото
- В налаштуваннях увімкнений кошик
- Підключений мінімум один стандартний спосіб оплати

### Умови потрапляння в кампанію CPC (за перехід):
- Замовляють здебільшого телефоном або послуги
- Статус "в наявності" або "під замовлення"
- Є хоча б одне фото

### ВАЖЛИВО:
Товари зі статусом "чернетка", "видалений", "прихований", "немає в наявності"
НЕ залучають покупців навіть якщо додані до кампанії!

## 2. ЗАПУСК КАМПАНІЙ У КАТАЛОЗІ PROSALE
URL: https://support.prom.ua/hc/uk/articles/360016549118

### Системні кампанії (автоматичні):
- "Товари з комісією за замовлення" — всі товари через кошик
- "Товари з комісією за перехід" — всі послуги і товари за телефоном
- Видалити системні кампанії або товари в них НЕ можна

### Запуск:
- Натиснути "Звичайний" — кампанія без обмежень по бюджету і терміну
- Показ починається одразу після запуску
- Потрібен мінімум один стандартний спосіб оплати

## 3. СТВОРЕННЯ КОРИСТУВАЦЬКИХ КАМПАНІЙ
URL: https://support.prom.ua/hc/uk/articles/360004972498

### Як створити:
1. Каталог ProSale → кнопка "Створити"
2. Вибрати модель оплати (за замовлення або за перехід)
3. Додати товари або групи
4. Натиснути "Звичайний" для запуску

### Комісія:
- Базова = єдина комісія категорії (не редагується)
- Комісія = ціна товару × єдина комісія %
- При декількох одиницях — комісія за кожен товар

### Режими (тільки для Топ-продавців):
1. **Турбо** — комісія +50% від єдиної (CPA) або ×2 (CPC)
   - Рекламні блоки на Prom + топ-видача + Google реклама
2. **Більше продажів** — комісія +25% від єдиної
   - Топ-видача + Google реклама від Prom
3. **Економ** — комісія -50% від єдиної
   - Для товарів без конкурентів, з кращою ціною

### Правило кількох кампаній:
Якщо категорія в кількох кампаніях з різними режимами → видача за НАЙВИЩОЮ комісією

## 4. МОЖЛИВІСТЬ ПІТИ В МІНУС
URL: https://support.prom.ua/hc/uk/articles/360004971357

### Умови:
- Доступно для платного пакету (крім тарифів "Prom мікс 3 місяці" з 16.12.2025)
- Допустимий від'ємний баланс: -1 000 грн
- Товари не зникають з видачі ще 4 дні після вичерпання балансу

### Порядок:
1. Баланс = 0 → активується "піти в мінус"
2. Повідомлення в Viber/додаток/email
3. 4 дні або до -1000 грн → кампанії зупиняються
4. Для запуску — погасити ВСЮ заборгованість
5. Поповнити баланс можна протягом 7 календарних днів
6. Якщо не поповнити — блокування кабінету або розірвання договору

### ВАЖЛИВО для нас:
- Стежити за балансом Prom!
- При балансі < 200 грн — поповнити
- Налаштувати сповіщення в Viber

## 6. РІЗНОВИДИ ТОВАРІВ В КАМПАНІЯХ PROSALE
URL: https://support.prom.ua/hc/uk/articles/4402326829841

### Правила:
- Товари додаються в кампанію РАЗОМ з різновидами автоматично
- Якщо додав основний товар → всі різновиди потрапляють автоматично
- Якщо додав кілька різновидів → основний товар і решта різновидів теж додаються
- Нові різновиди автоматично потрапляють в кампанію якщо основний товар вже там
- Видалити лише різновид НЕ можна — тільки весь товар з усіма різновидами
- Видалення з користувацьких кампаній доступне, з системних — НЕ можна

### Комісія для різновидів:
- Всім різновидам встановлюється єдина комісія за категорією
- Якщо увімкнений Економ/Більше продажів/Турбо — комісія цього режиму

### ВАЖЛИВО для нас (TOPTUL):
- Якщо товар "немає в наявності" — він додається в кампанію але НЕ відображається
- Коли товар перейде в "В наявності" — автоматично з'явиться в кампанії
- Це означає: достатньо налаштувати кампанію один раз → автооновлення наявності через фід → товари автоматично з'являються/зникають з видачі

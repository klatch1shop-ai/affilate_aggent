## Формула ціноутворення з CPA

```python
def calculate_price(feed_price, marketplace='prom', category='ручний інструмент'):
    # Закупка з знижкою 12% від TOPTUL
    zakupka = feed_price * 0.88
    
    # CPA з БД
    cpa = {'prom': 0.15, 'epicentr': 0.15, 'rozetka': 0.0}[marketplace]
    
    # Доставка
    delivery = 20  # середня
    
    # Мінімальна ціна з маржею 20%
    min_price = (zakupka + delivery) / (1 - cpa) * 1.20
    
    # Округлення до 10 грн
    return round(min_price / 10) * 10
```

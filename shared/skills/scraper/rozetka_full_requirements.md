## КРИТИЧНІ ПОМИЛКИ (блокують публікацію)

### 1. СПЕЦСИМВОЛИ В ТЕКСТІ
Обов'язкова заміна в будь-якому тексті (назва, опис, параметри):
- " → &quot;
- & → &amp;
- > → &gt;
- < → &lt;
- ' → &apos;
НЕ стосується самих XML тегів — тільки текст всередині тегів!

### 2. ФОТО — обов'язкові
- Мінімум 1 фото, максимум 15
- Мінімальний розмір: 400x400 px (оптимально 1000x1000)
- Тільки https посилання
- БЕЗ пробілів, кириличних символів, амперсандів & в URL
- Перше фото — фронтальний вид товару
- БЕЗ рук, сторонніх предметів на першому фото
- БЕЗ написів іноземною мовою
- Не дублювати фото в одному товарі
- БЕЗ водяних знаків
- Без фото — розміщення НЕМОЖЛИВЕ

### 3. ЦІНА
- Тег price не може бути 0 або порожнім
- Тільки UAH
- Ціна на Розетці не може бути вищою ніж в інших магазинах продавця

### 4. КАТЕГОРІЇ
- Кожен товар у правильній кінцевій категорії Розетки
- В одній категорії прайсу — товари тільки однієї категорії Розетки
- rz_id = ID категорії на сайті Розетки (для автоматичного маппінгу)
- ID категорій НІКОЛИ не змінювати після публікації

### 5. ПАРАМЕТРИ (param name)
- Мінімум 3 параметри на товар
- Параметри відповідають фільтрам категорії Розетки
- Назви параметрів — однією мовою (українська)
- Значення параметра — максимум 500 символів
- БЕЗ порожніх значень
- Довідник параметрів: seller.rozetka.com.ua/main/goods-manage/references
- БЕЗ параметрів — розміщення НЕМОЖЛИВЕ

### 6. VENDOR (виробник)
- Обов'язковий тег
- Назва бренду як у виробника (не КАПС, не ТМ/ТОВ/ФОП)
- Має збігатися з брендом в name_ua
- Якщо бренд є на Розетці — писати точно як там

### 7. УНІКАЛЬНІСТЬ НАЗВ
- Всі назви в прайсі унікальні
- Немає двох однакових name або name_ua
- Додавати артикул або характеристику для унікальності

## ФОРМАТ НАЗВИ ТОВАРУ

### Формула:
Тип товару Бренд Модель Характеристики (Артикул)

### Правила:
- Максимум 255 символів, оптимально до 60
- Починається з великої літери
- БЕЗ розділових знаків: ком, крапок, тире, дефісів (крім тих що в назві моделі)
- БЕЗ реклами: "Від виробника", "Оновлена версія", "Топовий", "Акція", "Знижка", "Розпродаж", "Новинка", "Покращений"
- БЕЗ спецсимволів: λ, Ω, ™, ½, @, ^, *
- НЕ писати всю назву ВЕЛИКИМИ ЛІТЕРАМИ
- Бренд у назві = бренд у тегу vendor
- Артикул вказувати в дужках
- Мова: українська (name_ua) або російська (name)
- Інші мови заборонені

### Правильні приклади для інструменту:
- Ключ рожковий TOPTUL 8x10 мм (AAEJ0810)
- Викрутка-тріскачка TOPTUL 19-в-1 (GAAR1002)
- Набір головок торцевих TOPTUL 1/4" 32 предмети (GCAI3201)
- Домкрат гідравлічний підкатний TORIN 3 т (T83002)

### Заборонені приклади:
- КЛЮЧ РОЖКОВИЙ 8x10 (всі великі)
- Ключ рожковий, якісний, від виробника TOPTUL (кома, реклама)
- Ключ рожковий TOPTUL (Харків) (місто в назві)

## ОПИС ТОВАРУ (description_ua)

### Що дозволено:
- Технічна інформація про конкретний товар
- HTML форматування в CDATA
- Структурований текст: призначення + характеристики

### Що ЗАБОРОНЕНО:
- Фото, відео, посилання в описі
- Ціни, знижки в описі
- Інформація про магазин/доставку/гарантію
- Інформація про інші товари
- Дублювання назви товару
- Рекламні фрази

### Формат в XML:
```xml
<description_ua><![CDATA[<p>Технічний опис українською.</p>]]></description_ua>
```

### Допускається без опису — якщо вказані всі характеристики

## СТРУКТУРА XML ФАЙЛУ

```xml
<?xml version="1.0" encoding="UTF-8"?>
<yml_catalog date="YYYY-MM-DD hh:mm">
  <shop>
    <name>Назва магазину</name>
    <company>Назва компанії</company>
    <url>https://your-site.com/</url>
    <currencies>
      <currency id="UAH" rate="1"/>
    </currencies>
    <categories>
      <category id="1" rz_id="ROZETKA_CATEGORY_ID">Назва категорії</category>
    </categories>
    <offers>
      <offer id="SKU123" available="true">
        <price>999</price>
        <currencyId>UAH</currencyId>
        <categoryId>1</categoryId>
        <picture>https://example.com/photo1.jpg</picture>
        <vendor>Бренд</vendor>
        <article>SKU123</article>
        <stock_quantity>10</stock_quantity>
        <name>Тип товару Бренд Модель (Артикул)</name>
        <name_ua>Тип товару Бренд Модель (Артикул)</name_ua>
        <description_ua><![CDATA[<p>Опис.</p>]]></description_ua>
        <param name="Параметр">Значення</param>
      </offer>
    </offers>
  </shop>
</yml_catalog>
```

## НАЯВНІСТЬ (stock_quantity)
- Обов'язковий тег
- Ціле число ≥ 0
- 0 = немає в наявності
- available="true" + stock_quantity≥1 = товар активний
- available="false" = товар неактивний

## ТЕХНІЧНІ ВИМОГИ XML
- Кодування UTF-8
- ASCII символи 0-31 заборонені (крім 9, 10, 13)
- URL товару за RFC-1738
- Статична URL адреса файлу (не змінювати!)
- ID товарів і категорій НІКОЛИ не змінювати після публікації

## ПОМИЛКИ З ДОСВІДУ (наші прайси)

### Прайс від 15 квітня (3262 товари) — помилки:
1. Спецсимволи не замінені на XML коди
2. Фото не відкривались (images.prom.ua без прямого доступу)
3. Ціна = 0
4. Всі товари в одній категорії
5. Vendor не заповнений
6. 220 дублів назв
7. Замало параметрів

### Прайс від 7 травня (8303 товари) — помилки:
1. 4398 товарів без параметрів
2. 220 дублів назв
3. Параметри не відповідають фільтрам категорій Розетки

## ВАЖЛИВО від Софії
"Прайси від постачальників не беремо в роботу"
Потрібно самостійно готувати XML з правильними параметрами
відповідно до фільтрів категорій Розетки.

Параметри брати з: вкладка "Характеристики" у вже опублікованих товарів
та з фільтрів зліва в категорії на сайті Розетки.

## GOOGLE APPS SCRIPT — оновлення наявності
Можна автоматично оновлювати stock_quantity через Google Sheets + Apps Script:
- Скрипт читає залишки з Prom API
- Оновлює Google Sheet з наявністю
- Генерує XML і публікує на хостингу
- Розетка автоматично підтягує оновлений файл

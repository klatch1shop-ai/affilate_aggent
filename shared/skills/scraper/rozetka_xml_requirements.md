# Вимоги до XML прайс-листа Rozetka

## Коли використовувати
При генерації XML файлу для Rozetka, перевірці товарних карток, виправленні назв, описів і параметрів.

## Структура XML файлу

```xml
<?xml version="1.0" encoding="UTF-8"?>
<yml_catalog date="YYYY-MM-DD hh:mm">
  <shop>
    <name>Назва магазину</name>
    <company>Назва компанії</company>
    <url>https://your-site.com/</url>
    <currencies>
      <currency id="UAH" rate="1"/>
    </currencies>
    <categories>
      <category id="1" rz_id="ROZETKA_CATEGORY_ID">Назва категорії</category>
    </categories>
    <offers>
      <offer id="SKU123" available="true">
        <price>999</price>
        <currencyId>UAH</currencyId>
        <categoryId>1</categoryId>
        <picture>https://example.com/photo1.jpg</picture>
        <vendor>Бренд</vendor>
        <article>SKU123</article>
        <stock_quantity>10</stock_quantity>
        <name_ua>Тип товару Бренд Модель Характеристика (Артикул)</name_ua>
        <description_ua><![CDATA[<p>Опис товару українською.</p>]]></description_ua>
        <param name="Характеристика">Значення</param>
      </offer>
    </offers>
  </shop>
</yml_catalog>
```

## Обов'язкові елементи offer
- `id` — латиниця + цифри, без кирилиці та пробілів, НІКОЛИ не змінювати після публікації
- `available` — true/false
- `price` — числове значення в UAH
- `currencyId` — UAH
- `categoryId` — id з блоку categories
- `picture` — мін. 1, макс. 15 фото. Тільки https, без кирилиці в URL
- `vendor` — бренд (має збігатись з назвою в name_ua)
- `stock_quantity` — ціле число, 0 = немає в наявності. ОБОВ'ЯЗКОВИЙ
- `name_ua` — назва українською
- `description_ua` — опис українською в CDATA
- `param name` — характеристики (мін. 3-5 параметрів)

## Вимоги до назви (name_ua)

**Формула:** `Тип товару Бренд Модель Колір Характеристики (Артикул)`

### Правила:
- Починається з великої літери (Тип товару)
- Максимум 255 символів, оптимально до 60
- Бренд у назві = бренд у тегу `<vendor>`
- БЕЗ ком, крапок, тире, дефісів (крім тих що в назві моделі)
- БЕЗ рекламних слів: "Акція", "Знижка", "ТОП", "Оновлена версія", "Від виробника"
- БЕЗ спецсимволів: λ Ω ™ ½ @ ^ *
- Назви УНІКАЛЬНІ — не може бути двох однакових
- Не писати всю назву ВЕЛИКИМИ ЛІТЕРАМИ

### Правильні приклади:
- `Ключ рожковий TOPTUL 8x10 мм (AAEJ0810)`
- `Набір викруток TOPTUL 6 предметів (GDD-006)`
- `Кліщі TOPTUL для зняття хомутів (JEAG0108)`

### Заборонено:
- `КЛЮЧ РОЖКОВИЙ 8x10` (все великими)
- `Ключ рожковий, якісний, від виробника TOPTUL` (рекламні слова, кома)
- `Ключ рожковий TOPTUL (Харків-1) КХШМ` (назви міст, незрозумілі скорочення)

## Вимоги до опису (description_ua)

- Тільки інформація про конкретний товар
- Заборонено: фото, відео, посилання на сайти, ціни, інформація про магазин/доставку
- Заборонено: інформація про інші товари
- Без дублювання назви товару в описі
- Максимум 50 000 символів
- HTML теги — в CDATA

## Вимоги до фото (picture)

- Мінімум 400x400 px, оптимально 1000x1000 px, максимум 4000x4000 px
- Тільки https посилання
- Максимум 15 фото на товар
- Перше фото — фронтальний вид без обрізки
- Товар має займати 70-80% площі зображення
- БЕЗ написів російською мовою
- БЕЗ рук та сторонніх предметів на першому фото
- Не дублювати фото в межах одного товару
- Не можна використовувати Google Диск для фото

## Вимоги до параметрів (param)

- Назва параметра в атрибуті `name`
- Значення не може бути порожнім
- Перелік параметрів = фільтри категорії на сайті Rozetka
- Для типів ComboBox/List — використовувати `paramid` і `valueid`

## Вимоги до категорій

- `rz_id` в тегу category = id категорії Rozetka (ключовий для автоматичної прив'язки)
- В одній категорії прайсу — товари лише однієї категорії Rozetka
- Назва категорії = назва на сайті Rozetka
- id категорії ніколи не змінювати після публікації

## Технічні вимоги XML

- Кодування UTF-8
- Символи в тексті замінювати: `"` → `&quot;`, `&` → `&amp;`, `>` → `&gt;`, `<` → `&lt;`
- Заборонені ASCII символи 0-31 (крім 9, 10, 13)
- URL товару за стандартом RFC-1738
- Статична URL адреса файлу (не змінювати)

## Заборонені категорії без узгодження
- Зарядні станції — потребують окремого узгодження з менеджером

## НАЗВА ТОВАРУ
Формула: Тип + Особливість + Бренд + Модель + Характеристики + Колір + (Артикул)
Розміри: через малу "х" з пробілом (60х60х5 см)
Набори: через "/" (3,0 л/2,5 л)
Кількість: 2в1 3в1 (без пробілів)
Бренд: з великої літери мова оригіналу БЕЗ CAPSLOCK
Артикул: у дужках в кінці

Правильно: Ключ рожковий TOPTUL 8х10 мм (AAEJ0810)
Правильно: Викрутка-тріскачка TOPTUL 19в1 (GAAR1002)
Заборонено: коми крапки CAPSLOCK реклама (акція знижка топ новинка)

## ФОТО
- Мінімум 1 максимум 10 рекомендовано 2-8
- Мінімум 500x500 px рекомендовано 1280x1280 px
- Білий або однотонний фон не чорний
- БЕЗ вотермарок написів логотипів адрес сайтів
- БЕЗ символіки РФ нацизму

## ХАРАКТЕРИСТИКИ
- Обов'язкові (*) — без них модерація неможлива
- Бренд реєструється в системі Єпіцентру
- Країна виробника — обов'язково
- Тільки українська мова

## ПАЙПЛАЙН ІМПОРТУ З PROM

Крок 1: Prom — Позиції — Експорт — YML — Українська мова
Поля: price name categoryId offer
Перевірити: фото без вотермарок бренд країна виробника

Крок 2: Єпіцентр — Імпорт — Імпорт з інших майданчиків
Вставити URL YML — Імпортувати
Статуси: ФАЙЛ ОБРОБЛЮЄТЬСЯ — ТОВАРИ ЗАВАНТАЖУЮТЬСЯ — ЗАВЕРШЕНО

Крок 3: Маппінг категорій
Після імпорту категорія буде відсутня — це нормально
Знайти: SELECT id final_category FROM epicentr_categories WHERE final_category ILIKE '%ключ%'
ВАЖЛИВО: якщо товар в Чернетці або На розгляді — при повторному імпорті характеристики ВТРАЧАЮТЬСЯ

Крок 4: Excel дозаповнення
1. Призначити набір атрибутів в кабінеті
2. Товари — Категорія — Експорт — XLS шаблон
3. Заповнити обов'язкові (*)
4. Імпорт — Завантажити XLS

## XLS ШАБЛОН ЄПІЦЕНТРУ
Назва_позіції — назва (обов'язково)
Опис — опис (обов'язково)
Ідентіфікатор_товара — артикул SKU (обов'язково)
Унікальний_ідентифікатор — ID для оновлення існуючих
Назва_Характеристики_1 — назва параметра
Одиниця_виміру_1 — мм кг шт
Значення_Характеристики_1 — значення
(блоки 1 2 3 повторюються)

## АВТООНОВЛЕННЯ ЗАЛИШКІВ

2. Набір атрибутів призначений
3. Обов'язкові (*) заповнені

6. Назва за форматом
7. Опис є
8. Бренд зареєстрований

Статуси: Чернетка — На модерацію — На розгляді (1-3 дні) — Опубліковано

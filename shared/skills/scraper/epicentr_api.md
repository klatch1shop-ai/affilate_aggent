# Епіцентр API — документація

## Внутрішній API (без офіційної документації)

### Пошук товарів
GET https://epicentrk.ua/api/catalog/search/
Параметри:
- q: пошуковий запит
- per_page: кількість (рекомендовано 20)
- page: сторінка
- sort: popularity / price_asc / price_desc

### Категорії товарів
GET https://epicentrk.ua/api/catalog/categories/

### Обов'язкові заголовки
```python
headers = {
    "Referer": "https://epicentrk.ua/",
    "X-Requested-With": "XMLHttpRequest",
    "User-Agent": "Mozilla/5.0 ..."
}
```

### Формат відповіді
```json
{
  "items": [
    {
      "id": "123456",

      "availability": true,
      "images": ["https://..."]
    }
  ],
  "total": 1500
}
```

## Популярні категорії Епіцентр
- Будівельні матеріали
- Інструменти
- Сантехніка
- Електрика
- Меблі
- Побутова техніка
- Садовий інвентар

## Дропшипінг через Епіцентр
- Офіційна програма дропшипінгу: partner.epicentrk.ua
- Знижка дропшиперам: 5-15% від роздрібної ціни
- Доставка: Нова Пошта, Укрпошта
- Мінімальне замовлення: немає
- Оплата: передоплата або при отриманні

## Важливо
- API нестабільний — може змінюватись
- Рекомендовано не більше 10 запитів/хвилину
- При помилці 503 — пауза 60 секунд

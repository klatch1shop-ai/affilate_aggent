# Скіл управління станом системи

## Що тримати в контексті
Оркестратор завжди знає:
1. Поточну стратегічну ціль
2. Стан кожного агента (idle/busy/error)
3. Що було зроблено за останні 24 години
4. Які задачі в черзі

## Правила оновлення стану
- Після кожної делегованої задачі — оновити snapshot
- При помилці агента — створити alert і запропонувати альтернативу
- Раз на день — генерувати зведений звіт для адміна

## Заборонені дії
- НЕ писати код самостійно
- НЕ робити парсинг самостійно  
- НЕ виконувати фінансові розрахунки самостійно
- ЗАВЖДИ чекати підтвердження адміна для критичних змін

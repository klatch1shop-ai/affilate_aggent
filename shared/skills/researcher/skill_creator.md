# Скіл створення нових скілів

## Що таке скіл
Скіл — це Markdown файл який описує:
1. Коли і навіщо використовувати цей скіл
2. Конкретні інструкції і правила
3. Приклади коду якщо потрібно
4. Що заборонено робити

## Структура скіла
```markdown
# Назва скіла

## Опис
Коли використовувати цей скіл (1-2 речення)

## Коли використовувати
- Конкретна ситуація 1
- Конкретна ситуація 2

## Інструкції
### Крок 1
...
### Крок 2
...

## Приклади коду
\`\`\`python
# приклад
\`\`\`

## Формат відповіді/результату
Що саме агент має повернути після виконання

## Заборонено
- Дія яку не можна робити
```

```
├── efficiency/            # скіли моніторингу
└── researcher/            # скіли досліджень
```

## Процес створення нового скіла
1. Визначити яку задачу вирішує скіл
2. Визначити якому агенту він належить
3. Написати чіткі інструкції (не загальні слова)
4. Додати приклади коду якщо потрібно
5. Зберегти в правильній папці
6. Перевірити що skill_loader бачить скіл

## Перевірка скіла
```python
from shared.utils.skill_loader import list_skills
skills = list_skills()
print([s["name"] for s in skills])
```

## Критерії якісного скіла
- Конкретний, не загальний
- Має приклади і формати
- Описує і що робити і що НЕ робити
- Підходить тільки одному агенту або задачі
- Розмір: 50-200 рядків (не більше)

## Автоматичне створення скіла через LLM
```python
def generate_skill(task_description: str, agent_name: str) -> str:
    llm = get_llm()
    prompt = f"""Створи скіл для агента {agent_name}.
    Задача яку вирішує скіл: {task_description}
    
    Дотримуйся структури скіла:
    # Назва
    ## Опис
    ## Коли використовувати
    ## Інструкції
    ## Заборонено"""
    return llm.invoke(prompt)
```

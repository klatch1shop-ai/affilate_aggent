# Скіл code review

## Що перевіряти
1. Обробка помилок (try/except)
2. Логування важливих подій
3. Безпека (немає відкритих паролів/токенів)
4. Читабельність коду
5. Відповідність задачі

## Формат відповіді
```
СТАТУС: OK / ПОТРЕБУЄ ВИПРАВЛЕНЬ
ПРОБЛЕМИ:
- [опис проблеми і де]
РЕКОМЕНДАЦІЇ:
- [конкретна рекомендація]
```

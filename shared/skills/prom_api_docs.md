# Prom.ua API
- Base URL: https://my.prom.ua/api/v1
- Auth: Authorization: Bearer PROM_API_TOKEN
- GET /products/list — список товарів, пагінація через page_from_id, limit макс 100
- GET /orders/list — замовлення
- PUT /products/edit — редагування товару
- POST /products/set_presence — змінити наявність

# Скіл звіту продуктивності

## Метрики для кожного агента
- Кількість виконаних задач за добу
- Кількість помилок
- Середній час виконання задачі
- Статус (idle/busy/error)

## Оцінка продуктивності
- Відмінно: 0 помилок, черга порожня
- Добре: < 2 помилок, черга < 3
- Потребує уваги: > 5 помилок або черга > 5
- Критично: агент офлайн або > 10 помилок

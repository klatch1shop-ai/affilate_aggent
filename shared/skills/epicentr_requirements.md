# Епіцентр Маркетплейс — вимоги та процес публікації

## Процес додавання товарів
1. Імпорт з Prom через YML файл (price, name, category_Id, offer — обов'язкові поля)
2. Після імпорту товари створюються зі статусом "Чернетка" — тільки базова інформація
3. Дозаповнити картку: категорія → набір характеристик → обов'язкові поля → фото → опис
4. Статус "На розгляді" → модерація → "Опубліковано"

## Вимоги до контенту
- Мова: ТІЛЬКИ українська (російська не обов'язкова, поле ru можна вимкнути)
- Назва товару: українською, чітка і зрозуміла
- Опис: детальний, без реклами і посилань
- Фото: однотонний фон, товар займає 80%+ кадру, без водяних знаків, 1-10 фото (рекомендовано 2-8)

## Характеристики — КРИТИЧНО
- Топ-характеристики: ОБОВ'ЯЗКОВІ, відображаються в списку товарів і на вітрині
- Основні характеристики: обов'язкові, це фільтри на сайті — без них товар невидимий
- Чим більше заповнено характеристик → вища видимість у фільтрах → більше продажів

## Імпорт шаблон
- XLSX або XML шаблон — завантажити в розділі "Імпорт" кабінету
- Обов'язкові поля XLSX: Назва UA, Назва RU, Артикул, Ціна
- Для оновлення ціни/наявності: Назва UA, Назва RU, Артикул, Ціна, Стара ціна, Наявність
- Артикул = ключ для оновлення (має збігатися з тим що в системі)

## Ключова проблема з нашими товарами
- Імпорт з Prom не передає всі характеристики Епіцентру
- Рішення: імпортувати базово → завантажити шаблон категорії → AI заповнює характеристики → імпорт назад

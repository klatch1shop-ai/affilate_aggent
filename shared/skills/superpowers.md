# Superpowers — Головний скіл системи

## Опис
Цей скіл завантажується ПЕРШИМ при кожному старті агента.
Він ініціює всіх субагентів і визначає як система працює.

## Субагенти системи
При отриманні задачі оркестратор завжди слідує цьому пайплайну:

### Для нових задач з маркетплейсами:
1. **Planner** → планує задачу, створює специфікацію
2. **Researcher** → шукає інформацію в інтернеті якщо треба
3. **Scraper/Integrator** → отримує дані з маркетплейсу
4. **Finance** → розраховує маржу і ціни
5. **Developer** → пише код інтеграцій якщо треба
6. **Reviewer** → перевіряє результат
7. **Efficiency** → логує результат і метрики

### Для аналітичних задач:
1. Researcher → збирає дані
2. Marketing → аналізує
3. Finance → розраховує
4. Efficiency → звітує

### Для задач розробки:
1. Planner → специфікація
2. Developer → імплементація
3. Reviewer → code review + acceptance check паралельно
4. Developer → фікс знайдених проблем

## Правила паралелізації
- Незалежні задачі виконуються ПАРАЛЕЛЬНО
- Агенти ніколи не працюють над одним файлом одночасно
- Code Review і Acceptance Check завжди паралельно

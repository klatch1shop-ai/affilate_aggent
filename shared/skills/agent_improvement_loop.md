# Система самовдосконалення агентів

## Принцип
Кожен агент після виконання задачі:
1. Записує результат в таблицю agent_results (PostgreSQL)
2. Оцінює якість результату за шкалою 0-10
3. Якщо оцінка < 7 → логує що пішло не так
4. Раз на добу developer_agent аналізує всі низькі оцінки
   і оновлює відповідні skill файли

## Метрики для дропшипінгу
- Scraper агент: % успішних запитів без блокування
- Marketing агент: точність аналізу трендів
- Finance агент: точність розрахунку маржі
- Scraper: актуальність залишків (оновлення < 1 год)

## Механізм оновлення скілів
Developer агент раз на тиждень:
1. Читає всі логи з оцінкою < 7
2. Аналізує паттерни помилок
3. Генерує оновлення для skill файлів
4. Створює git commit з описом що покращено

## MCP пріоритети для підключення
1. Bright Data MCP → вирішує Cloudflare блокування
2. Zapier MCP → автоматизація звітності
3. Apify MCP → готові скрапери маркетплейсів
4. Google Sheets MCP → живий моніторинг цін

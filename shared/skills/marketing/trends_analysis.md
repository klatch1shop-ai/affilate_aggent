# Скіл аналізу трендів

## Процес аналізу
1. Отримати дані Google Trends за останні 3 місяці
2. Визначити товари з висхідним трендом (trend = "up")
3. Знайти пов'язані пошукові запити
4. Оцінити конкурентність ніші

## Критерії вибору товару для дропшипінгу
- Середній інтерес > 40 (за шкалою Google Trends)
- Тренд висхідний або стабільний
- Є попит в Україні (geo=UA)
- Маржа після комісії маркетплейсу > 20%

## Формат звіту
```
Товар: [назва]
Тренд: [up/stable/down]
Середній інтерес: [число]
Рекомендація: [так/ні і чому]
```

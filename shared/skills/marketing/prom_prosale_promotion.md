## ЩО ТАКЕ PROSALE

ProSale — інструмент для відображення та просування товарів на Prom.

Дві моделі оплати:
- **CPA** (Cost Per Action) — відсоток від ціни товару при замовленні через кошик
- **CPC** (Cost Per Click) — фіксована сума в грн за перехід на картку товару

Результати використання ProSale:
- В 2.5 рази більше переходів
- В 3 рази більше замовлень

## РЕЖИМИ ПРОСУВАННЯ

### Економ (тільки для Топ-продавців)
- Комісія знижена на 50% від єдиної
- Базова видача в каталозі

### Звичайний (базовий)
- Єдина комісія за категорією
- Стандартна позиція в каталозі

### Більше продажів
- Підвищений пріоритет у видачі
- Комісія = єдина + додаткова %
- Формула: ціна × (комісія_режиму - єдина_комісія) = додаткова сума

### Турбо
- Найвищий пріоритет — топ видачі
- Рекламні блоки на Prom
- Реклама Google від Prom
- Найвища комісія

## ЯК ФОРМУЄТЬСЯ ВИДАЧА (позиція в каталозі)

Фактори що впливають на позицію:
1. **Режим ProSale** — Турбо > Більше продажів > Звичайний > Економ
2. **Якість обслуговування** — відгуки 95%+ дають додатковий пріоритет
3. **Пром-оплата** — товари з Пром-оплатою мають додатковий пріоритет
4. **Якість картки товару** — фото, опис, характеристики
5. **Конкурентна ціна** — порівняння з іншими продавцями
6. **Релевантність** — відповідність запиту покупця

## УМОВИ ДЛЯ ВІДОБРАЖЕННЯ В КАТАЛОЗІ

Обов'язково:
- Мінімум 1 фото
- Статус "опублікований"
- Статус "є в наявності" або "під замовлення"
- Товар доданий до кампанії ProSale

## КРОКИ ДЛЯ ПІДВИЩЕННЯ ЗАМОВЛЕНЬ

### 1. Якість картки товару
- Мінімум 3-5 якісних фото (1000x1000px)
- Детальний опис з ключовими словами
- Всі характеристики заповнені
- Правильна назва (Тип + Бренд + Модель + Характеристики)

### 2. Ціна
- Моніторити ціни конкурентів (наш market_price_analyzer.py)
- Ціна трохи нижче середньої по ринку
- Враховувати CPA комісію в ціні

### 3. Відгуки
- 95%+ позитивних відгуків = додатковий пріоритет
- Просити покупців залишати відгуки
- Швидко відповідати на питання

### 4. Пром-оплата
- Підключити Пром-оплату = додатковий пріоритет в видачі
- Покупці довіряють більше

### 5. Режим просування
- Починати з "Звичайний"
- При достатній маржі переходити на "Більше продажів"
- "Турбо" — тільки для дорогих товарів з великою маржею

## ФОРМУЛА РОЗРАХУНКУ ПРИБУТКУ З PROSALE

```python
def calculate_profit(price, zakupka, cpa_rate, delivery=20, mode='normal', mode_extra=0):
    # CPA комісія
    commission = price * cpa_rate
    
    # Додаткова комісія за режим
    extra = price * mode_extra if mode != 'normal' else 0
    
    # Чистий прибуток
    profit = price - zakupka - commission - extra - delivery
    
    return profit

# Приклад BCRA1613:
# price=310, zakupka=198, cpa=0.15, delivery=20
# profit = 310 - 198 - 46.5 - 0 - 20 = 45.5 грн (14.7% маржа)

# З режимом "Більше продажів" (+5%):
# profit = 310 - 198 - 46.5 - 15.5 - 20 = 30 грн (9.7% маржа)
```

## ОПТИМАЛЬНА СТРАТЕГІЯ ДЛЯ TOPTUL

### Фаза 1 (зараз) — Звичайний режим:
- Запустити всі товари в "Звичайний"
- Зібрати перші відгуки
- Моніторити конверсію (перегляди → замовлення)

### Фаза 2 (після 10+ відгуків) — Оптимізація:
- Товари з маржею > 30% → "Більше продажів"
- Топ-товари за попитом → "Більше продажів"
- Решта → "Звичайний"

### Фаза 3 (після 50+ відгуків) — Масштабування:
- Аналіз які товари дають найбільший ROI
- Топ 20% товарів → "Турбо"
- Решта → "Більше продажів" або "Звичайний"

## КЛЮЧОВІ ПОКАЗНИКИ ДЛЯ МОНІТОРИНГУ

- CTR (перегляди / покази) — ціль > 2%
- Конверсія (замовлення / перегляди) — ціль > 1%
- ROI = (прибуток / витрати на просування) × 100%
- Вартість замовлення (CPA) — має бути < прибутку з замовлення

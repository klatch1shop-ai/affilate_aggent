## РОЗЕТКА — вимоги до картки

### Документація:
- Назва: https://sellerhelp.rozetka.com.ua/p217-product-title.html
- Фото: https://sellerhelp.rozetka.com.ua/p216-product-images.html
- Характеристики: https://sellerhelp.rozetka.com.ua/p210-product-characteristics.html
- Опис: https://sellerhelp.rozetka.com.ua/p212-product-description.html

### Назва (name_ua):
Формула: Тип + Бренд + Модель + Колір + Характеристики
- Макс 255 символів
- Модель — назва/код як у виробника
- Колір — кирилицею або латиницею відповідно до фото
- Характеристики — відмінні властивості що впливають на вибір
- Значення в назві МАЮТЬ відповідати характеристикам і опису
- НЕ вказувати різні варіанти типу або повний перелік характеристик
- ЗАБОРОНЕНО: "Від виробника", "Оновлена версія", рекламні фрази

### Фото:
- Мінімум 1, максимум 15 (рекомендовано 5-10)
- Мінімум 400x400 px (рекомендовано 1000x1000+)
- Фото МАЮТЬ відповідати назві, характеристикам і опису
- НЕ можна показувати асортимент товарів
- Тіні/світіння/відбиття — не повинні обриватись
- Для вузьких довгих товарів — правильні ракурси
- Перше фото — фронтальний вид без рук і сторонніх предметів

### Характеристики (param):
- Мінімум 2-3 параметри (рекомендовано 10+)
- Інформація МАЄ відповідати фото, опису та назві
- Максимум 255 символів у значенні параметра
- Якщо характеристика відсутня в категорії Розетки — вказати в описі
- Нові значення додаються автоматично при завантаженні
- Тільки українська мова в назвах параметрів

### Ціна:
- НЕ може бути необгрунтовано вища за середню ринкову
- Порівняння з іншими майданчиками

## ЄПІЦЕНТР — вимоги до картки

### Документація:
- Загальні вимоги: https://supportm.epicentrk.ua/zagalnivymogydokontentu/
- Фото: https://supportm.epicentrk.ua/vymogydovizualnogokontentuyakpravylnoobratyzobrazhennyavashogotovaru/
- Категорії: https://supportm.epicentrk.ua/categoriitabrendytovariv/

### Назва:
Формула: Тип + Особливість + Бренд + Модель + Характеристики + Колір + (Артикул)
- Розміри через "х" малу (60х60х5 см)
- Набори через "/" (3,0 л/2,5 л)
- Кількість: 2в1, 3в1 (без пробілів)
- Бренд з великої літери, мова оригіналу, БЕЗ CAPSLOCK
- ЗАБОРОНЕНО: коми, крапки як розділові знаки, реклама

### Фото:
- Мінімум 1, максимум 10 (рекомендовано 2-8)
- Мінімум 500x500 px (рекомендовано 1280x1280+)
- Білий або однотонний фон (НЕ чорний)
- БЕЗ вотермарок, написів, логотипів, адрес сайтів
- БЕЗ символіки РФ, нацизму

### Характеристики:
- Обов'язкові (*) — без них модерація НЕМОЖЛИВА
- Бренд має бути зареєстрований в системі Єпіцентру
- Країна виробника — обов'язково
- Тільки українська мова

## АЛГОРИТМ ОЦІНКИ КАРТКИ (0-100 балів)

```python
def score_card_universal(product, marketplace='prom'):
    score = 0
    issues = []
    
    # ФОТО (25 балів)
    pics = len(product.get('pictures', []))
    min_req = {'prom': 1, 'rozetka': 1, 'epicentr': 1}
    rec = {'prom': 3, 'rozetka': 5, 'epicentr': 3}
    if pics == 0:
        issues.append('КРИТИЧНО: немає фото')
    elif pics < rec[marketplace]:
        score += int(25 * pics / rec[marketplace])
    else:
        score += 25
    
    # НАЗВА (20 балів)
    name = product.get('name_ua', '')
    max_len = {'prom': 120, 'rozetka': 255, 'epicentr': 150}
    if len(name) < 20:
        issues.append('Назва занадто коротка')
        score += 5
    elif len(name) > max_len[marketplace]:
        score += 10
    else:
        score += 20
    
    # ОПИС (20 балів)
    desc = len(product.get('description', ''))
    if desc == 0:
        issues.append('Немає опису')
    elif desc < 100:
        score += 5
    elif desc < 300:
        score += 12
    else:
        score += 20
    
    # ХАРАКТЕРИСТИКИ (20 балів)
    params = len(product.get('params', {}))
    min_params = {'prom': 3, 'rozetka': 3, 'epicentr': 5}
    if params == 0:
        issues.append('КРИТИЧНО: немає характеристик')
    elif params < min_params[marketplace]:
        score += 5
        issues.append(f'Мало характеристик ({params} < {min_params[marketplace]})')
    elif params < 10:
        score += 12
    else:
        score += 20
    
    # ЦІНА (15 балів)
    if product.get('price', 0) > 0:
        score += 10  # базово, точне порівняння через market_price_analyzer
    
    return score, issues
```

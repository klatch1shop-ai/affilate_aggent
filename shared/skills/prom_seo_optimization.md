# Prom.ua — SEO оптимізація карток для першої сторінки

## Алгоритм ранжування (реальні фактори)
- Відповідність назви до пошукового запиту — головний сигнал
- Швидкість переведення замовлення в "В обробці" — до 5 хвилин (прямий фактор ранжування!)
- Контент-рейтинг картки — інструмент в кабінеті продавця показує заповненість
- Поведінкові сигнали: перегляди, CTR, конверсія
- Активність магазину: регулярне додавання нових товарів
- Кількість і якість відгуків
- Конкурентна ціна
- ProSale підключення для топових позицій

## Оптимальна назва товару
- Використовувати всі 110 символів
- Формат: Головний ключовий запит + Бренд + Модель + характеристика
- Приклад: "Ключ тріскачковий TOPTUL 1/4" 72 зубці з реверсом CHHI1208"
- НЕ починати з бренду якщо бренд не є пошуковим запитом

## Опис товару
- Мінімум 300 символів для ранжування
- Природні ключові слова без спаму
- Унікальний текст — не копія з сайту постачальника
- Структура: що це → для чого → переваги → характеристики

## Характеристики (атрибути)
- Заповнити МАКСИМАЛЬНО — впливають на фільтри категорії
- Порожні характеристики = товар випадає з фільтрів = невидимий покупцю
- SEO-налаштування: Інструменти вебмайстра → Налаштування метатегів

## Фото
- Мінімум 3 фото для конкурентних позицій
- Перше фото: білий/однотонний фон, товар займає 80%+ простору
- Решта: контекст використання, деталі, комплектація
- Без водяних знаків і рекламних написів

## ProSale
- Активувати для топових позицій після оптимізації контенту
- Спочатку оптимізація картки — потім реклама (інакше гроші витрачені даремно)

## SEO через Google
- Prom дозволяє налаштовувати метатеги → трафік з Google
- Розділ: Інструменти вебмайстра та SEO → Налаштування метатегів
- Підключити Google Search Console через Prom

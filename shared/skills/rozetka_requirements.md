# Розетка Маркетплейс — вимоги до XML прайсу

## Критичні помилки (файл не пройде валідацію)
- Відсутній тег stock_quantity в кожному offer → додати: <stock_quantity>10</stock_quantity>
- HTML теги в description та description_ua → очистити через strip_html()
- Неунікальні назви товарів → кожна назва має бути унікальною
- Відсутні param name у 317+ товарів → без параметрів товар не потрапляє у фільтри

## Формат назви
- Структура: Тип товару Бренд Модель (Артикул)
- БЕЗ дефісів між словами, БЕЗ ком
- Бренд в назві = значення в тегу <vendor>
- Приклад: "Ключ тріскачковий TOPTUL 45 зубців 1/2 укорочений (CHDI1613)"

## Вимоги до фото
- Мінімум 400x400px, оптимально 1000x1000px
- Перше фото: фронтальний вид, товар не обрізаний, на передньому плані
- Без дублів фото в межах одного offer
- Текст на фото тільки українською або англійською
- Без написів російською мовою

## Категорії
- Один offer = одна кінцева категорія Розетки
- Тріскачні ключі і Воротки — різні категорії (не змішувати)
- Зарядні станції потребують окремого узгодження з менеджером

# Скіл розрахунку маржі

## Формула
```
Ціна продажу = Закупівельна ціна × 1.35 (мінімум)
Комісія Prom = Ціна продажу × 0.05
Комісія Rozetka = Ціна продажу × 0.12
Чистий прибуток Prom = Ціна продажу - Закупівля - Комісія Prom
Чистий прибуток Rozetka = Ціна продажу - Закупівля - Комісія Rozetka
```

## Мінімальні пороги
- Чистий прибуток на Prom: мінімум 50 грн з товару
- Чистий прибуток на Rozetka: мінімум 80 грн з товару
- Якщо менше — товар не рентабельний

## Курс USD
Завжди використовувати актуальний курс НБУ.

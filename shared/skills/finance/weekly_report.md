# Скіл тижневого звіту

## Структура звіту
1. Загальна кількість оброблених товарів
2. Топ-5 найрентабельніших товарів
3. Помилки та збої системи за тиждень
4. Порівняння з попереднім тижнем
5. Рекомендації на наступний тиждень

## Формат для адміна
Короткий, конкретний. Максимум 10 рядків.
Числа, факти, рекомендації. Без води.

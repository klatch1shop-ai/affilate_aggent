# AGENTS.md — правила для Codex у репозиторії дропшипінгу (affilate_aggent)

Читай повністю перед роботою. Це **робоча система**: код звідси розгортається на
сервер, де за розкладом працюють агенти замовлень, синхронізація фідів і
Telegram-бот. Помилка тут = втрачене замовлення чи зламаний фід.

## Твоя роль

Ти — **робітник**. Завдання ставить менеджер (сесія Claude), запускає тебе через
`~/affiliate-sales-pilot/scripts/codex_task.py --repo ~/agent-system …` з
переліком дозволених файлів (`--allow`) і командами перевірки (`--verify`).
Робиш **одне завдання**, пишеш звіт, зупиняєшся. Рішення — за менеджером.

## Завдання й суддя

- Завдання: `docs/tasks/TASK-NN-<назва>.md`.
- **Тести в `tests/` — умова приймання. Їх написано до тебе, і змінювати їх
  не можна.** Якщо тест здається хибним — опиши це у звіті, не правь.
- Звіт: `docs/reports/TASK-NN-report.md` — що зроблено, дослівний вивід тестів,
  що не вдалося, питання.

## Заборонено

- змінювати будь-що поза `--allow` — запуск зупиниться;
- `git commit`, `git push`, будь-які операції з гілками;
- `.env`, секрети, токени — не читати й не виводити;
- звертатись до API маркетплейсів, Нової Пошти, Telegram, серверу під час
  роботи — модулі мають перевірятись тестами з підробленими даними;
- чіпати живого бота `tg_dispatcher/main.py`, агентів `agents/`, інструменти
  `tools/`, спільний код `shared/`, фіди `output/`, дані `data/`;
- встановлювати пакети. Лише стандартна бібліотека Python, якщо завдання не
  каже інакше. Інтерпретатор: `venv/bin/python`.

## Самостійні рішення

- `want` містить відповідний поріг, діапазон або короткий опис вимоги; для успішної перевірки `hint` порожній.
- Початок кадру рівно на 5.0 с уже поза першими п’ятьма секундами. Умова «після 60 %» для CTA реалізована строгим порівнянням `>`.
- Тривалість — сума тривалостей реплік; за недодатної загальної тривалості темп дорівнює 0, щоб уникнути ділення на нуль.
- Порожній гачок, як і відсутній, замінюється першою реплікою. Перед перевіркою початку гачка прибираються крайні пробіли.
- Шингли зберігають межі слів за пробілами й вилучають з кожного слова символи, що не є літерами або цифрами. Для `n < 1` повертається `ValueError`.

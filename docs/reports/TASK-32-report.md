## Самостійні рішення

- `parse_date` приймає лише два зазначені формати рядків; інші типи та формати
  повертають `None`.
- Числові перегляди — `int` або `float`; числові рядки не перетворюються.
- Округлення у звіті — стандартне `round` Python (рівно половина — до парного).
- Непозитивний ліміт дає порожній результат; у `collect` пошук не викликається.
- Майбутні дати проходять фільтр свіжості, бо не старіші за заданий поріг.

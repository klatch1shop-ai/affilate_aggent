## Самостійні рішення

- Час без часової зони відхиляється; час із зоною нормалізується до UTC, як у `helper/confirm.py`. Дата створення зберігається з фіксованою точністю до мікросекунд для коректного сортування текстових дат у SQLite.
- Етапи мають бути додатними цілими числами без повторів: інакше запис за номером етапу був би неоднозначним. Вхідний порядок не важливий, звірки сортуються за етапом.
- Перевіряється, що всі докази — рядки. Пробільні subject/text/fact відхиляються; прийняті тексти зберігаються без змін.
- Ідентифікатор — перші 12 hex-символів SHA-256 від JSON-масиву subject/text/decision; структуроване кодування усуває неоднозначність склеювання рядків.
- Звірки зберігаються як JSON у записі гіпотези; факт і підсумковий статус оновлюються атомарно. Достроковий запис факту дозволено, оскільки завдання не встановлює заборони.

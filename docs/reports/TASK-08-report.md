# Звіт TASK-08

## Що зроблено

- `ops/__init__.py` — порожній файл пакета.
- `ops/pg_backup.py` — реалізовано `dump_cmd`, `list_cmd`, `backup`, `rotate` лише стандартною бібліотекою.
- Дамп записується в `.dump.part`, перевіряється на непорожність та через `pg_restore --list` зі stdin, після успіху атомарно перейменовується в `.dump`.
- За невдачі дампу чи перевірки тимчасовий файл видаляється, ротація не запускається. Ротація використовує UTC-час із назви й зберігає щонайменше три найновіші архіви.
- Зовнішніх дій та git commit не виконувалося; команди Docker у тестах виконує підроблений `run`.

## Перевірка

Для обох запусків встановлено `PYTHONDONTWRITEBYTECODE=1` і `PYTEST_ADDOPTS='-p no:cacheprovider'`, щоб не створювати побічних файлів.

Команда:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTEST_ADDOPTS='-p no:cacheprovider' venv/bin/python -m pytest tests/test_pg_backup.py -q
```

Дослівний вивід (код завершення 0):

```text
........                                                                 [100%]
8 passed in 0.02s
```

Команда:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTEST_ADDOPTS='-p no:cacheprovider' venv/bin/python -m pytest tests/ -q -k "not pg_backup"
```

Дослівний вивід (код завершення 0):

```text
........................................................................ [ 27%]
........................................................................ [ 54%]
........................................................................ [ 81%]
................................................                         [100%]
264 passed, 8 deselected in 0.22s
```

## Самостійні рішення

- Каталог бекапів створюється за потреби. `now` без часового поясу відхиляється через `ValueError`.
- Ротація пропускає некоректні назви/дати, каталоги й символічні посилання; однакові часові позначки впорядковуються за назвою. Межа строку зберігання строга: видаляються лише старші файли.
- Порожня назва бази та роздільники шляху в ній відхиляються, щоб файл залишався всередині каталогу бекапів.
- Повторний успішний запуск для тієї самої бази й UTC-хвилини замінює попередній дамп лише після перевірки нового.
- Помилки команд містять назву операції та код завершення; сирі stderr і тексти винятків не повертаються, щоб не розкривати приватних даних. Помилка очищення тимчасового файлу повідомляється явно.
- Таймаути належать переданому виконавцю `run`; власного запуску процесів або повторних спроб модуль не додає.

## Що не вдалося, питання

Невдалих приймальних перевірок і питань немає. Перевірка `pg_restore --list` відповідає завданню, але не є фактичним відновленням бази. Реальний Docker/Postgres, cron і копіювання на ноутбук не запускалися; розгортання виконує рецензент.

## Зміни

- `tg_dispatcher/privacy.py`: спільне маскування телефонів у різних форматах та email.
- `tg_dispatcher/inbox/__init__.py`: пакет ядра.
- `tg_dispatcher/inbox/model.py`: незмінна модель, перевірки полів, переведення часу в UTC.
- `tg_dispatcher/inbox/normalize.py`: нормалізація Rozetka та Prom без контактних полів.
- `tg_dispatcher/inbox/store.py`: SQLite, усунення дублів, прив'язки Telegram, курсори, пошук чатів без відповіді.
- `tg_dispatcher/inbox/collect.py`: обхід сторінок, фільтр першого запуску, збереження курсора при помилках і перевищенні межі сторінок.
- `tg_dispatcher/inbox/render.py`: HTML-картки та нагадування з маскуванням контактів.
- `tg_dispatcher/inbox/reply.py`: послідовна перевірка відповіді та режими off/draft/live; лише план дії.
- `tg_dispatcher/ai_brain/commands.py`: змінено виключно `_safe`, яка викликає `privacy.mask_private`.

Тести не змінювалися. Зміни обмежено дозволеними шляхами.

## Перевірки

Перед запуском встановлено `PYTHONDONTWRITEBYTECODE=1` та
`PYTEST_ADDOPTS='-p no:cacheprovider'`, щоб не створювати кеші поза дозволеними шляхами.

Команда:

```text
venv/bin/python -m pytest tests/test_privacy.py tests/test_inbox.py -q
```

Дослівний вивід, код завершення 0:

Команда:


Дослівний вивід, код завершення 0:

Додатково перевірено в пам'яті на вигаданих даних випадок 5 сторінок при
`max_pages=2`: два нові повідомлення записано, попередній курсор збережено,
помилка містить обидва числа, повторний запуск не повертає дублів.

```text
Неповний обхід: курсор збережено, повідомлення записано, повтор без дублів — OK
```

`git diff --check`: порожній вивід, код завершення 0.

## Самостійні рішення

- За однакового часу повідомлень останнім вважається запис, доданий пізніше.
- «Старше N хвилин» означає строго більше N; хвилини округлюються вниз.
- UTC зберігається з однаковою точністю до мікросекунд для коректного сортування ISO-рядків.
- Курсор не зменшується, якщо отриманий список містить лише старіші чати.
- Помилки нормалізації та запису окремого чату також блокують зсув курсора;
  обробка решти чатів продовжується. Тексти винятків не розкриваються.
- Контакти в тілі картки маскуються перед обрізанням, HTML екранується після
  обрізання, щоб не залишати фрагменти контактів та не розривати HTML-сутності.
- Для відхиленої відповіді `body` порожнє; після знаходження чату його реквізити
  повертаються навіть у разі подальшої відмови.
- Збирач відхиляє час без зони та `max_pages < 1` через `ValueError`.

Консультація надто широко називає обрізання виводу невпровадженим: у перевірених делегаторах межі вже є. Не виміряні фактичні токени, кеш-хіти, частоти запусків, бойові SQL-дампи та секретна конфігурація — це поза дозволеним локальним дослідженням.

## Самостійні рішення

- Повторний запит користувача трактовано як вимогу відновити сумісність викликів без `now`, попри початкову вимогу обов’язкового аргументу. У `pending_requests()` не додано прихованого поточного часу: без аргументу діє стара поведінка. Для `apply_results()` поточний UTC забезпечує час запису відмови.
- Явний `now` зберігає детерміновану поведінку TASK-04B. Виклики з явним UTC-часом у `run()` збережено.
- Звіт має назву з великою `B`, як вказав користувач.

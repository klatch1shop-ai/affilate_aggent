## Самостійні рішення

- Числові рядки перетворюються на float; булеві значення, NaN, нескінченність, недодатні й неперетворювані значення вимірів вважаються відсутніми даними. Непридатний дільник повертає `None`.

- Від’ємний `min_profit` відхиляється також у `select`, зокрема для порожнього входу.

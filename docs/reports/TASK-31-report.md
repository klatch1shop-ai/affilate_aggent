## Самостійні рішення

- `UNITS` зберігає пару «канонічна одиниця, множник» для кожного позначення.
- Ліміт рахує унікальні спроби читання, включно з невдалими; дублі не витрачають ліміт. Це відповідає приймальному тесту. Від’ємний ліміт обробляється як нульовий.
- Коректний JSON, який не є об’єктом, відхиляється через `ValueError`: контракт вимагає поля об’єкта.
- Елементи списків також обрізаються та нормалізуються; порожні елементи пропускаються, порожній список стає `None`.
- Помилки містять шлях і назву типу винятку, без довільного тексту винятку читача.
- Межі одиниць у регулярному виразі не дозволяють сприймати початок невідомого слова як відому одиницю.

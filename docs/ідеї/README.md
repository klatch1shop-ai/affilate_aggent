# Ідеї — місце, де не треба бути правим

Сюди пишемо «а що якби». Чотири розділи:

```
## Проблема      що болить, з числом якщо є
## Гіпотеза      що могло б допомогти
## Як перевірити найдешевший спосіб дізнатись, правда це чи ні
## Чому ще ні    що заважає почати
```

Ідея стає напрямом ЛИШЕ коли власник каже «робимо». Доти вона тут і не
засмічує дорожню карту обіцянками.

# Напрями

**Мета · Де зараз · Зроблено · Відкрито · Чекає рішення.**

`[!]` = потрібне рішення власника, сам не вирішую.

## Поруч
* [рішення/](../рішення/) — ADR: чому зроблено саме так. Не редагуються;
  якщо рішення змінилось — новий файл із посиланням на старий.
* [ідеї/](../ідеї/) — що могло б бути, без зобов'язань.
* [SYSTEM_INVENTORY.md](../SYSTEM_INVENTORY.md) — що зараз запущено.
* [work_queue.md](../work_queue.md) — дрібні наступні кроки.

## Правило
Правити **одразу при зміні**, не збирати заново раз на місяць. Міра —
`docs/research/DEVLOG_AND_BOARD.md`: із 290 файлів 125 не чіпали понад
місяць, і чим файл більший, тим він застаріліший.

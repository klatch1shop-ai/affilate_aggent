# EVA — Маркетплейс
Оновлено: 09.10.2026

## Мета
Новий майданчик, домовленість свіжа. Вийти з косметикою.

## Де зараз
Довідку зібрано, фіду ще немає.

Умови: **мінімум 50 SKU**, формат **YML**, два IP у whitelist. Дропшипінг
нас не стосується — працюємо як B2B.

## Зроблено
* Зібрано довідку по умовах і формату.
* Еталон картки конкурента: шаблон назви та **9 обов'язкових
  характеристик**; свічки міряються вагою, не розміром.
* Доступ до даних: Cloudflare блокує curl. Легальний шлях — **оголошений
  sitemap і прямі URL категорій**, не пошук. `btk_id` ≠ `eva_id`.

## Відкрито
* **Прогалина у відкритих категоріях.** З 22 розділів підтверджено лише
  «Гель для душу». Решта 21 не перевірена — не знаємо, чи вони відкриті.
* Гілка 18+ жива, і там продає сам EVA Partners.

## Чекає рішення

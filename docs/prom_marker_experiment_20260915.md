# Маркер-експеримент: чи шукає Prom за ключовими словами (старт 15.09)

**Дозвіл:** власник, 15.09 (разом з оцінкою чату).
**Навіщо:** на наявних даних чистий тест ключів неможливий. Генератор будує
ключі зі слів назви, тож будь-який запит із ключів частково збігається з
назвою. Це розділений збіг, а за правилом Prom («Облік ключових слів у
пошуку та тегах») такий товар не показується. Усі попередні докази
«ключі не працюють», зокрема 4 браузерні випадки, мали такий дизайн.

## Дизайн

| | Група UA | Група RU |
|---|---|---|
| маркер | «зорвінтал» | «квербаліс» |
| поле | лише `keywords_ua` | лише `keywords` |
| карток | 10 | 10 |

- 20 карток з **20 різних категорій**, випадково (seed 20260915). Усі на
  вітрині й у наявності, поза вибіркою заміру видимості й тестами.
  Перелік і prom_id: `data/prom/marker_experiment.json`.
- Маркера **немає** в назві й описі, лише в ключах. Отже, запит із одного
  слова має збіг тільки в полі ключів, і розділеного збігу немає.
- **Негативний контроль до старту:** обидва маркери дають 0 результатів в
  українському і російському пошуку (HTML, 15.09 ~16:20). Перевірку
  браузером з обома блоками видачі — див. журнал.
- Крок `tools/prom_marker_step.py` — останній у `prom_postprocess.py`.
  Перевірено на копії опублікованого фіду: змінено рівно 20 карток,
  0 порушень, лише потрібне поле.
- Публікація **15.09 о 19:40**, імпорт вмісту — нічний (~01–03 за Києвом).

## Перевірка

- **Щодня** (16, 17, 18.09), браузером, з обома блоками видачі:
  - запити: маркер в українському і російському пошуку, по 2 прогони;
  - запис у `docs/prom_marker_experiment_log.tsv`;
  - запуск: `venv/bin/python tools/prom_marker_check.py`.
- **Чи імпортовано:** `tools/prom_marker_check.py --api` на сервері.
  - Для групи RU маркер видно в API `keywords`.
  - Для групи UA ознака лише `date_modified`, бо українських ключів API не віддає.

## Як читати результат

| Імпорт | Маркер знайдено | Висновок |
|---|---|---|
| так | в основному блоці | ключі індексуються повноцінно |
| так | лише в частковому блоці | ключі працюють як «друга частина видачі» (як у документації) |
| так | ніде, кілька днів поспіль | ключі цього поля пошук не використовує |
| ні | — | тест нічого не показує, чекати імпорту |

Порівняння UA з RU показує, чи є різниця між мовами.

## Завершення

Після висновку (або 7 днів без знаходжень) — `"active": false` у
`data/prom/marker_experiment.json`, наступна публікація прибере маркери.
Перевірити, що вони зникли з фіду.

# Наступна партія знахідок (картка за карткою), 12.09 вечір

Метод той самий: дефект на картці → правило на весь каталог → повна збірка
(генератор + постобробка) → звірка з попередньою збіркою, позитивний і
негативний контроль → розгортання. Публікує cron о 7:40.

## 1. Мінімум 5 фраз — перевірено, як ви просили

Добір до 5 додав 516 фраз у 311 картках. Серед них знайшлися погані:
теги протилежної статі (~11) і недоречні теги категорії. Додано два
фільтри добору: стать і відповідність тегу типу товару. «эротические
боди…» на нетематичних картках 26 → 0, «садо мазо» 943 → 0, «фаллоимитаторы
дилдо» 403 → 365 (лишились лише у фалоімітаторах).

## 2. Мішане написання — новий тип

Латинські літери всередині кириличних слів у текстах постачальника:
«свечa», «верcия», «10cм», «Гуcтая смазка», «Сlassic», «Сockring», «Wіnе»,
«рH». Для пошуку це інші слова. Виправлено в назвах, описах і ключах обох
мов тими самими правилами, що вже працюють для фіду TOPTUL. Окремо: бренд,
набраний кириличними двійниками («Кііrоо» замість Kiiroo, 7 описів), і
злиплі слова («пробкаWooomy», «Honeyпросто»).
**142 мішаних слова → 1** (залишилась звичайна одруківка).

## 3. Ключі укр. — тип товару брався через прийменник

Знайшлося, коли виправлене написання змінило ключі кількох карток:

| Було | Карток/фраз | Стало |
|---|---|---|
| «насадка член» | 265 фраз | «насадка на член» |
| «свічка вигляді» | 93 | «свічка» |
| «змазка водній» | 34 | «змазка», + «змазка на водній основі» |
| «подвійна кільце / дилдо / віброяйця» | 50 | узгоджено в роді |
| «класична конусна густа змазка» (форма пробки на змазці) | 24 картки | прибрано |
| «для пар» як тип товару | 2 картки × 9 фраз | «смартвібратор» |
| «гідропомпа діаметр», «віброкуля стимулювальними» | ~10 карток | одне слово перед брендом |

Перша спроба — брати прийменникову групу в сам тип («вібратор для
клітора») — погіршила картки: зламала узгодження («чорна вібратор для
клітора») і витіснила брендові фрази. Відкинув після перегляду вибірки;
тепер тип короткий, а група йде окремою фразою.

Заміри по всьому фіду: фраз з обрубком у кінці 75 → 0; неузгоджених пар
прикметник+іменник (груба евристика) 952 → 506; карток з 9 фразами
1679 → 1736, з ≤5 фразами 1085 → 914.

**Негативний контроль:** поза українськими ключами змінились лише поля з
мішаним написанням (назви 31, описи 73, рос. ключі 10). Ціни,
характеристики, категорії — 0.

## 4. Відкладено в наступну партію

- «свічка trip» на 5 масажних свічках (слово з опису англійською);
- тип із характеристики підтверджується словом із хвоста назви:
  «Мастурбатор з вібрацією… три віброкулі» → тип «віброкулі»;
- «штучна / гумова вагіна» як синонім на мастурбаторах-ротиках;
- рос. теги «возбуждающее средство» на масажних свічках.

## Питання

1. Чи варто на картках, де назва постачальника має прийменникову групу
   («насадка на член», «кріплення для душу»), ставити її також першою
   фразою ключів, а не лише однією з дев'яти, — чи порядок фраз у полі
   для Prom не має значення?
2. 506 неузгоджених пар — здебільшого хибні спрацювання мого лічильника
   («насадка кокос» — іменник + бренд). Чи є сенс доводити лічильник до
   точного (словник родів), чи досить вибіркової ручної перевірки по 20
   карток на партію?

**Детектор перевірено до того, як довіряти числу.** 30 випадкових

Детектор переписано окремим інструментом із вбудованими контролями:
11 відомо хибних фраз мусять бути позначені, 19 відомо правильних — ні;
без проходження контролів числа не видає. Перша версія контролі не пройшла
(«вагінальний» відкидався як іменник, «змазка» вважалась прикметником) —
виправлено до заміру. Після цього: 22 з 30 випадкових — справжні (73 %).

**Що дав точний детектор** — нові джерела помилок, усі виправлено:
- шаблони властивостей лише в чоловічому роді: «гіпоалергенний маска»,
  «їстівний масажна олія», «охолоджувальний пробка»;
- рід брався з останнього слова типу: «золота колесо вартенберга»,
  «чорне маска серце»;
- «латексний безлатексні презервативи»;
- тип без іменника: «густа анальна», «шикарний вакуумний», «смарт» —
  кілька латок замінено одним правилом (початок назви до бренду/коми/
  прийменника, іменник + до двох означень);
- **головне:** зона з назви вважалась суперечністю характеристиці.
  «Звуковий стимулятор клітора» з «Призначення: для стимуляції грудей»
  (помилка постачальника) втрачав усі фрази з типом. Карток з 1 фразою
  25 → 1, з 2 фразами 24 → 9.

**Підсумок проти опублікованого фіду:** детектор 754 фрази в 517 картках →
1 (і та не помилка); карток з 9 фразами 1679 → 1847, з ≤5 фразами
1077 → 787. Ручна перевірка 20 випадкових змінених карток (вибірка
перевірена `sample_bias_check.py`, відхилення 0.0σ): 20 з 20 покращено
або без погіршення. Поза українськими ключами змін немає. Мішане написання
додано в AGENT_RULES 11.6 четвертим підвидом.

Порядок фраз, як ви радите, лишаю як є. Наступна партія — свічка trip,
тип із хвоста назви (віброкулі), «штучна вагіна» на ротиках, «возбуждающее
средство», плюс нове: тип «віброяйця» (множина з характеристики) на
одиночному віброяйці.

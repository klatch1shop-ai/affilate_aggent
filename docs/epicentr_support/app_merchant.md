# Мобільний додаток для продавців

- Початок співпраці
- Робота з товарами
- Опрацювання замовлень
- Юридичний блок
- Білінг
- F. A. Q.
На підставі п.3 Додатку 5 до Субліцензійного договору, ця інструкція є його невідʼємною частиною.

## Мобільний додаток для продавців
Завантажити мобільний додаток на смартфон ви можете за посиланням:
- iOS - завантажити в App Store
- Android - завантажити в Google Play
Зверніть увагу! Мінімальна версія ОС, на якій працює додаток:
- iOS:13.6
- Android: версія платформи - 5.0 / рівень API - 22.
Щоб увійти до особистого кабінету продавця, після встановлення додатку, вам потрібно авторизуватись.
Для цього, перейдіть у мобільний додаток та введіть ваш Email / номер мобільного телефону і пароль, які ви зазвичай використовуєте для входу, у відповідні поля на сторінці авторизації, що відкрилась після заставки.
Далі, натисніть на кнопку "Увійти".
Після успішної авторизації, система запропонує вам пройти автоонбординг для ознайомлення з роботою додатку.
Якщо ви бажаєте пропустити цей крок, натисніть кнопку "Потім" у вспливаючому вікні "Бажаєте ознайомитись з роботою додатку?".
Далі, відкриється головна сторінка розділу "Більше", у хедері якої вам будуть доступні для перегляду:
- Дані по вашій компанії.
- Дані по контрагентам.
- Дані авторизованого користувача.
- Ваші активні сервіси.
- Поточний стан основного та бонусного рахунків.
- Перейти до розділів:
- "Мій профіль"
- "Тарифи"
- "Звіти"
- "Транзакції"
- "Мова інтерфейсу"
- "Довідка"
З головного меню додатку, яке розташоване у нижній частині екрану, ви зможете перейти до розділів "Замовлення" , "Товари" , "Сповіщення" та "Більше" .
У розділі "Замовлення" ви зможете:
- Переглядати картки замовлень.
- Опрацьовувати вхідні замовлення.
- Фільтрувати замовлення по статусу, даті, даних покупця, способу та статусу оплати для пришвидшення процесу пошуку потрібних.
- Сортувати замовлення за датою.
Щоб переглянути та опрацювати замовлення, натисніть на його картку у загальному списку всіх замовлень.
В детальній картці ви зможете змінювати статус дзвінка, а також статус замовлення.
У розділі "Товари" ви зможете:
- Масово змінювати статус та наявність товарів.
- Змінювати ціну обраного товару.
- Переглядати сторінки опублікованих товарів на вітрині.
- Фільтрувати товари по набору атрибутів, статусу, бренду, категорії, ID для пришвидшення процесу пошуку потрібних.
- Сортувати товари за датою додавання та назвою.
У розділі "Сповіщення" будуть відображатись повідомлення стосовно ваших замовлень, балансу, нових акцій та вигідних пропозицій.
У розділі "Більше → Тарифи" вам буде доступна інформація стосовно комісій (роялті) за продані товари в залежності від категорій.
З розділу "Більше → Звіти" ви зможете з авантажувати на свій смартфон звіти про продані товари.
Для пришвидшення процесу пошуку у розділі потрібного звіту, ви можете скористатись фільтром по статусу та / або даті формування.
У розділі "Більше → Транзакції" будуть відображатись усі транзакції по замовленням, а також транзакції на поповнення і коригування вашого балансу.
Для пришвидшення процесу пошуку потрібної транзакції, ви можете скористатись фільтрами:
- По номеру замовлення.
- По даті замовлення.
- По типу транзакції.
- По даті транзакції.
У розділі "Більше → Мова інтерфейсу" можливо змінити мову, на якій буде відображатись інтерфейс додатку.

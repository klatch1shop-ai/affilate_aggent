## Мобільний додаток
Мобільна версія особистого кабінету продавця, спеціально розроблена для вашої зручності. Опрацьовуйте вхідні замовлення, редагуйте ціни та наявність товарів, переглядайте транзакції та звіти про продані товари, чинні тарифи та інструкції по роботі з функціоналом навіть коли поруч немає комп'ютера.

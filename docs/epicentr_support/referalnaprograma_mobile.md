## Реферальна програма у мобільному застосунку
Реферальна програма у мобільному застосунку
В розділі "Запросити друга" доступний наступний функціонал:
- умови програми (Покажчик 1);
- загальна кількість друзів, які приєднались за умовами програми (Покажчик 2);
- загальна сума бонусу, отримана за приведених друзів (Покажчик 3);
- сума бонусу за кожного друга (Покажчик 4);
- історія нарахування бонусів (Покажчик 5);
- запросити друга для участі в програмі (Покажчик 6).
Для того, щоб ознайомитись з умовами реферальної програми, натисніть на іконку "і", яка розташована у правому верхньому кутку.
Для того, щоб переглянути історію нарахування бонусів по реферальній програмі, натисніть на вкладку "Історія бонусів" .
Надіслати запрошення для участі другу можна у вигляді QR-коду або посилання. Для того, щоб надіслати запрошення, натисніть на кнопку "Запросити через QR-код" / "Запросити друга" . У вікні, що відкрилось внизу екрана, оберіть додаток для надсилання запрошення. Примітка: після натискання на кнопку "Запросити через QR-код" відкриється сторінка з візуальним відображенням qr-коду, на якій натисніть на кнопку "Поділитись QR - кодом".

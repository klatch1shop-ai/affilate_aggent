## 1. Робота з Contract id:
Для отримання Contract id натисніть тут .
Важливо: Без внесеного Contract id в систему Маркетплейсу ви не зможете створювати ТТН. Після підписання договору із Meest Пошта ви зможете створювати ТТН із функцією "Післяплата" ("Зворотна доставка грошей"). Кошти за "Зворотну доставку грошей" будуть приходити на розрахунковий рахунок, який ви зазначили при підписанні договору із Meest Пошта. Для користувачів Епіцентр Маркетплейс будуть застосовані спеціальні тарифи на послуги доставки після підписання договору із Meest Пошта.

## 2. Створення ТТН
Звертаємо вашу увагу! Функція "Зворотна доставка грошей" буде доступна лише після підписання договору з Meest Пошта та для замовлень з типом оплати "Післяплата". Якщо за вашим Contract id  відсутня можливість створювати ТТН з функцією "Зворотна доставка грошей", то ви побачите відповідне повідомлення.
4. На сторінці "Створення накладної (номер замовлення)" у вас будуть відображені наступні блоки:
- Дані відправника (ПІБ, телефон, місто відправника та відділення Meest)
- Дані одержувача (ПІБ, телефон, місто одержувача та відділення Meest)
- Параметри посилки (зворотна доставка грошей, оціночна вартість, ширина, висота, довжина тощо).
1. Поля "Ім'я", "Прізвище", " По батькові" та "Телефон" автоматично будуть заповнені.
Зверніть увагу : дані полів "Ім'я", "Прізвище" та "Телефон" можна змінювати вручну зі сторінки "Створення накладної".
"Телефон" має бути вказаний саме той номер телефону, на який у вас зареєстрований кабінет Meest. Це потрібно для відображення даних замовлення у вашому кабінеті сервісу Meest. Зазначений номер телефону буде використовуватись для повернення посилки та оплати за послуги доставки. Рекомендуємо зазначати той номер телефону, за яким зручно буде оплачувати послуги та отримувати посилки.
- "Телефон" має бути вказаний саме той номер телефону, на який у вас зареєстрований кабінет Meest. Це потрібно для відображення даних замовлення у вашому кабінеті сервісу Meest.
- Зазначений номер телефону буде використовуватись для повернення посилки та оплати за послуги доставки. Рекомендуємо зазначати той номер телефону, за яким зручно буде оплачувати послуги та отримувати посилки.
2. Поля "Місто відправника" та "Відділення Meest" потрібно заповнити вручну, вибравши відповідне значення з випадаючого списку (відкривається при натисканні на рядок).
Блок "Дані одержувача"
1. Блок "Дані одержувача" заповнюється інформацією із замовлення. 2. Для редагування даних клієнта необхідно повернутися на сторінку деталей замовлення
Блок "Параметри посилки"
Зверніть увагу: функція "Зворотна доставка грошей" буде доступна лише після підписання договору з Meest Пошта та для замовлень з типом оплати "Післяплата". Для замовлень з типом оплати "Оплата карткою онлайн" - функція "Зворотна доставка грошей" буде вимкнена та недоступна.
У випадку, коли "Зворотна доставка грошей" може бути використана, значення поля "Сума грошового переказу" буде заповнена даними із замовлення.
Зверніть увагу! Сума грошового переказу не може перевищувати суму замовлення.
Примітка: при "Зворотній доставці грошей" кошти надходитимуть на розрахунковий рахунок, який ви вказали під час підписанні договору з сервісом Meest.
1. У пункті "Платник за доставку" сторону платника буде обрано відповідно до даних замовлення:
- якщо доставка безкоштовна - "Відправник";
- якщо доставка платна - "Одержувач".
- Якщо у замовленні лише один товар - його параметри автоматично будуть підтягуватися з даних товару
- Якщо у замовленні більше одного товару - параметри посилки потрібно буде внести вручну.
Зверніть увагу! Відділення Meest Пошти мають різні обмеження в габаритах посилок, місць та кількості місць в одній посилці.
5. Після заповнення даних натисніть кнопку "Створити накладну". 6. Після створення, номер ТТН буде збережено в замовленні. 7. Ви також можете скопіювати або завантажити накладну у pdf-форматі, натиснувши відповідну кнопку.

Зверніть увагу! Ви зможете бачити створену ТТН у своєму кабінеті Meest Пошта тільки якщо в даних відправника був зазначений номер телефону, на який зареєстровано ваш кабінет Meest Пошта.

3. Натисніть на номер замовлення, щоб відкрити його детальну картку. 4. У детальній картці замовлення справа внизу знайдіть блок "Посилка". 5. Натисніть на кнопку "кошик" для видалення накладної.

## Можливі помилки при роботі з ТТН
- відділення відправника не може відправити посилку зазначених габаритів;
- відділення отримувача не може прийняти посилку зазначених габаритів;
- відділення отримувача не може прийняти посилку оціночною вартістю понад 30 тис. гривень;
- термін дії договору з Meest Пошта вичерпано тощо.
Зверніть увагу! Для створення ТТН потрібно буде вказати габарити посилки, які не перевищують обмежень обраних відділень Meest Пошта.

# Поповнення балансу особового рахунку
Поповнення балансу особового рахунку
Для уникнення блокування компанії на маркетплейсі Епіцентр необхідно поповнювати баланс особового рахунку. Поповнити баланс особового рахунку можно двома способами:
- за реквізитами
- карткою

### Поповнення балансу за реквізитами
Поповнення балансу за реквізитами
Для того, щоб поповнити баланс за реквізитами виповніть наступні кроки:
- "Бухгалтерія" → "Транзакції" та натисніть на кнопку "Сформувати Рахунок" в блоці "Рахунок компанії" (Зображення 1, Покажчик 1, 2 та 3);
- "Налаштування" → "Налаштування компанії" → вкладка "Основне" та натисніть на кнопку "Сформувати Рахунок" в блоці "Поповнити рахунок компанії" (Зображення 2, Покажчик 1, 2, 3 та 4).
3. Натисніть на кнопку "Сформувати" (Зображення 2, Покажчик 6).
Примітка:
мінімальна сума поповнення за реквізитами - 10 гривень для внесення суми з копійками, вкажіть значення через кому Після чього буде сформовано платіжне доручення для оплати рахунку у форматі Excel, яке автоматично завантажиться на комп'ютер (Зображення 3).
- мінімальна сума поповнення за реквізитами - 10 гривень
- для внесення суми з копійками, вкажіть значення через кому
Після чього буде сформовано платіжне доручення для оплати рахунку у форматі Excel, яке автоматично завантажиться на комп'ютер (Зображення 3).
Важливо! При поповнені балансу необхідно:
- оплатити рахунок з рахунку ФОП або компанії, яка уклала договір з маркетплейсом Епіцентр;
- в призначені платежу вказати інформацію з платіжного дорученя (Зображення 3, Покажчик 1).
Зарахування коштів за допомогою поповнення балансу за реквізитами відбувається протягом 3–5 робочих днів, залежно від банку платника.
Важливо! Для коректно сформованого платіжного доручення перевірте наявність правильно заповнених даних, а саме:
- назва ФОП/ТОВ;
- номер договору;
- дату підписання договору.

### Поповнення балансу карткою
Поповнення балансу карткою
Для того, щоб поповнити баланс карткою виповніть наступні кроки:
1. Відкрийте один із розділів:
- "Бухгалтерія" → "Транзакції" та натисніть на кнопку "Поповнення онлайн" в блоці "Рахунок компанії" (Зображення 4, Покажчик 1, 2 та 3);
- "Налаштування" → "Налаштування компанії" → вкладка "Основне" та натисніть на кнопку "Поповнення онлайн" в блоці "Поповнити рахунок компанії" (Зображення 5, Покажчик 1, 2, 3 та 4).
2. У вікні "Створити платіж" , яке відкрилося, в полі "Введіть суму поповнення" введіть сумму поповнення балансу (Зображення 5, Покажчик 5).
3. Натисніть на кнопку "Оплатити через EasyPay" (Зображення 5, Покажчик 6).
Примітка:
- мінімальна сума поповнення карткою - 1 гривня
- для внесення суми з копійками, вкажіть значення через кому
Після чого в браузері відкриється вкладка "EasyPay - онлайн оплата послуг" , на якій оберіть один із варіантів для поповнення карткою (Зображення 6):
- Google Pay - натисніть на кнопку "GPay" (Покажчик 1);
- іншою карткою - заповніть поля:
- "Номер Картки" -  введіть номер картки з 16 цифр;
- "ММ/РР" - введіть термін дії картки;
- "CVV" - введіть СVV-код, який знаходиться на зворотній стороні картки;
- "Email" - введіть електронну пошту для отримання квитанції.
Для оплати рахунку натисніть на кнопку "Оплатити ... грн." (Покажчик 2).
Примітка: посилання на оплату карткою дійсне протягом 3х годин.
В результаті виконаних дій буде здійснено поповнення балансу.
Важливо! При поповненні балансу карткою комісія становить 1,25% від суми поповнення.
Переглянути транзакції поповнення рахунку ви можете у розділі "Бухгалтерія" → "Транзакції" в нижній частині сторінки. Відповідні транзакції матимуть запис "Поповнення" у колонці "Тип транзакції".

# Журнал ітерацій Prom: що змінили → що перевірили → результат

Швидкий цикл: зміна → фід на GitHub → власник тисне «Почати імпорт» у кабінеті
→ перевірка через 15–30 хв (API + SERP), без очікування нічного автоциклу.

Формат запису однаковий, щоб із журналу можна було зібрати звіт у підтримку
без переписування: **гіпотеза · зміна · перевірка · результат**.

## Ітерація 1 — прибрано сторонні посилання, вперше опубліковано keywords

**Гіпотеза:** посилання на сторонні сайти виключають товар із каталогу
ProSale (SKILL-14.3); keywords мають підняти видимість за фразами.

**Зміна:** `strip_links()` у генераторі — 257 тегів `<a href>` → 2 (обидва
YouTube), сторонні домени 12 → 0, «@» з назв прибрано. Разом із цим уперше
опубліковано 3806 полів `<keywords>`.

**Публікація:** 11.08 22:03, git blob `702e0a7aaf9341bc2b9a40e7b433ef89177bfd21`,
розмір збігається з файлом на usa1.

**Перевірка (11.08, 22:1x, до імпорту):** API на 5 SKU показує
`keywords: "Мастурбатори"` — тобто **назву категорії, підставлену Promʼом**,
а не наші фрази. `date_modified: 2026-08-10T23:00` — на добу раніше за нашу
публікацію.

**Результат: наші keywords Prom ще не бачив.** Висновок про їхню
(не)ефективність робити рано. Чекає на ручний імпорт.

## Ітерація 2 — ручний імпорт (готова до запуску)

**Гіпотеза:** після імпорту `keywords` у картці зміняться з «Мастурбатори» на
наші фрази, і картки почнуть зʼявлятися у видачі за ними.

**Дія власника:** кабінет → імпорт за посиланням
`https://raw.githubusercontent.com/klatch1shop-ai/noire-feed/main/noire_prom.xml`
→ «Почати імпорт».

**Перевірка (через 15–30 хв):**
1. `GET /products/by_external_id/EGG-001L` — чи `keywords` стали нашими,
   чи `date_modified` оновився;
2. повторний SERP по 3 контрольних запитах: `мастурбатор tenga`,
   `вібратор для клітора`, `анальна пробка з хвостом`;
3. порівняння з baseline 11.08.

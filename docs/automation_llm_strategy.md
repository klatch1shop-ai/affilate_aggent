# Чим автоматизувати: локальна модель, безкоштовні API чи взагалі без LLM

Мета проєкту — повністю автоматичний сервіс. Питання не «яку модель узяти»,
а «де модель узагалі потрібна». Відповідь на нього виявилась несподіваною.

## 1. Скільки роботи насправді потребує LLM

Аудит того, що зроблено за 15-16.08.2026 — приблизно 25 окремих механізмів:

| Механізм | Чим зроблено | LLM? |
|---|---|---|
| Пошукові фрази (8 на мову) | словники + узгодження за родом | ні |
| Транслітерація брендів | таблиця на 40 брендів | ні |
| Характеристики з тексту | офіційний довідник + пошук цілого слова | ні |
| Зіставлення назв постачальника | таблиця синонімів полів | ні |
| Дублікати фото | перцептивний хеш | ні |
| QR/штрихкоди на фото | pyzbar | ні |
| Знімки лінійки | той самий хеш + порівняння характеристик | ні |
| Скорочення назв | прийменникові вставки, regex | ні |
| Категорії | API майданчика | ні |
| Ціни й габарити постачальника | вхід у кабінет + розбір DOM | ні |
| Переклад описів рос. | **gemma3:4b локально** | **так** |
| Переписування описів | **потрібна модель** | **так** |

**Двадцять три з двадцяти пʼяти механізмів працюють без жодної моделі.**
Це головний висновок: автоматизація тут будується на офіційних довідниках,
детермінованих правилах і перевірках, а не на генерації. Модель потрібна
рівно там, де треба **створити текст**, якого немає.

Наслідок для планування: питання «чи вистачить безкоштовних лімітів» —
про 2 задачі з 25, а не про весь проєкт.

## 2. Де модель справді потрібна

**Переписування описів.** Єдине велике поле, яке в нас дослівно збігається
з десятками конкурентів (`docs/marketplace_seo_algorithm.md`). Обсяг:
5476 позицій × приблизно 1500 токенів входу й 500 виходу.

**Контроль якості згенерованого.** Валідатор уже написаний, але він ловить
формальні дефекти (мова, довжина, розмітка) і не бачить змісту — «Спрей
для кун-хулинга» пройшов його без питань.

## 3. Обмеження, яке вирішує все за нас

Наш асортимент — товари 18+. Практика показала: **хостингові моделі
відмовляються його обробляти.** На пробі NVIDIA NIM частина запитів
поверталась відмовами через фільтри безпеки, і це не налаштовується.

Те саме стосується безкоштовних рівнів Groq, Gemini, Mistral: у їхніх
умовах прямо сказано, що безкоштовний доступ оплачується вашими даними —
запити йдуть у навчання, — і контентні політики застосовуються суворіше,
ніж на платних.

Тобто для нашої ніші вибір не між «дешево й дорого», а між **локальною
моделлю й нічим**.

## 4. Що є локально

RTX 4050, 6 ГБ VRAM. Це визначає стелю:

| Модель | Розмір | Поведінка | Придатність |
|---|---|---|---|
| gemma3:4b | 3.3 ГБ | цілком у VRAM, ~2 с на текст | робоча конячка |
| qwen2.5:7b | 4.7 ГБ | вміщується, повільніше | перевірена непридатною для української |
| aya-expanse:8b | 5.1 ГБ | чверть на CPU, 14.6 с | якісніша, але вп'ятеро повільніша |

Арифметика для 5476 описів: gemma3:4b дає приблизно **3 години** на повний
прогін, aya-expanse — близько **22 годин**. Обидва варіанти реальні за ніч,
різниця лише в тому, скільки ночей.

## 5. Де безкоштовні API все ж корисні

Не для масового прогону, а для **фокусної групи в 30-50 позицій**, які ми
просуваємо. Там якість тексту важить більше за обсяг, і туди можна
віддати найкращу доступну модель — за умови, що вміст не порушує їхніх
правил (нейтральні категорії: лубриканти, косметика, аксесуари).

Ліміти безкоштовних рівнів станом на 2026:

| Провайдер | Ліміт | Вистачає на |
|---|---|---|
| Groq | 14 400 запитів/добу | увесь каталог за добу |
| Gemini (AI Studio) | ~1500 запитів/добу | 4 доби |
| Cerebras | ~1 млн токенів/добу | ~500 описів/добу |
| Mistral Experiment | ~1 млрд токенів/місяць | увесь каталог багаторазово |
| OpenRouter | ~30 моделей, ~20 запитів/хв | тести й порівняння |

**Але жоден не можна вважати надійним каналом для 18+.** Тому схема така:
локальна модель — основа й гарантія, безкоштовний API — прискорювач для
частини, що проходить їхні фільтри.

## 6. Практична схема

```
детерміновані механізми (23 з 25) ──► працюють завжди, безкоштовно
                                       нічого не потребують

переписування описів ──► gemma3:4b локально, нічний прогін
                          │
                          └─► фокусні 30-50 позицій: краща модель
                              (aya-expanse локально або безкоштовний API,
                               якщо категорія нейтральна)

контроль якості ──► детермінований валідатор + вибіркова очна перевірка
```

## 7. Що це дає далі

Зібрані сьогодні дані постачальника (`sexopt_dropship_price`) закривають
останню білу пляму: **маржа по кожній позиції**. Середня 48%.

Це дозволяє автоматизувати відбір: фокусна група більше не «на око», а
запит до бази — найвища маржа × наявність × унікальність. Далі на цю групу
йдуть описи, просування й вимір через 60 днів.

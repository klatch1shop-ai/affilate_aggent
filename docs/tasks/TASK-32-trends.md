## Інтерфейс
```python
def collect(queries, searcher, *, per_query=5, limit=20) -> dict
def parse_date(value) -> datetime.date | None
def velocity(video, now) -> float | None
def fresh(videos, now, *, days=30) -> list[dict]
def rank(videos, now, *, limit=10) -> list[dict]
def diff_topics(current, previous) -> dict
def report(ranked, diff, now) -> str
```

Ролик — словник: `{'id', 'title', 'url', 'channel', 'upload_date', 'views', 'duration'}`.

### `collect(queries, searcher, *, per_query=5, limit=20)`
`searcher(query, per_query) -> list[dict]`. Повертає `{'videos': [...], 'errors': [...], 'asked': N}`.
- Дублі запитів (після `strip`, без урахування регістру) пропускаються; порожній запит пропускається.
- Дублі роликів за `id` пропускаються — лишається перша поява.
- `limit` — максимум роликів у результаті; щойно набрано `limit`, решта запитів **не питається**.
- Виняток `searcher` → рядок у `errors` виду `'<запит>: <тип винятку>'`, обхід не зупиняється.
- Ролик без `id` або без `title` пропускається мовчки.
- `asked` — скільки запитів реально пішло в `searcher`.

### `parse_date(value)`
`'20260915'` і `'2026-09-15'` → `date(2026, 9, 15)`. `None`, порожнє, сміття → `None`.

### `velocity(video, now)`
Перегляди за добу: `views / max(днів від завантаження, 1)`. `now` — `datetime.date`.
Дата не розбирається або `views` не число → `None`. Майбутня дата → рахується як 1 день.

### `fresh(videos, now, *, days=30)`
Лишає ролики з датою не старішою за `days` днів (рівно `days` — лишається).
Ролики без дати **відкидаються**. Порядок вхідних даних зберігається.

### `rank(videos, now, *, limit=10)`
Сортує за `velocity` спадно, ролики з `velocity is None` відкидає. Однакова швидкість →
новіший вище; однакова дата → порядок входу. Повертає перші `limit`, кожен ролик —
**копія** словника з доданим ключем `'velocity'` (float). Вхідні словники не змінюються.

### `diff_topics(current, previous)`
Два списки рядків-тем. Нормалізація: `strip`, нижній регістр, кілька пробілів = один.
Повертає `{'new': [...], 'gone': [...], 'kept': [...]}` — **відсортовані за абеткою**, без дублів.

### `report(ranked, diff, now)`
- Перший рядок: `'📈 Радар трендів на DD.MM.YYYY'` (з `now`).
- Другий: `'Свіжих роликів: N'` (довжина `ranked`).
- Далі на кожен ролик два рядки:
  `'• {швидкість}/день · «{title}» — {channel}'` (швидкість — ціле, округлення до найближчого)
  і `'  {url}'`.
- Потім, якщо непорожні: `'Нові теми: a, b'` (`new`), `'Зникли: a, b'` (`gone`) — через `', '`.
- `ranked` порожній → замість переліку рядок `'Нема свіжих роликів'` (заголовок і теми лишаються).

## Відповіді на можливі питання
1. **`views` відсутній або `None`** — `velocity` повертає `None`, такий ролик у `rank` не потрапляє,
   але у `fresh` лишається (свіжість і швидкість — різні питання).
2. **`limit=0`** у `collect` — жодного виклику `searcher`, `asked == 0`.
3. **`channel` порожній** — рядок ролика лишається, після `—` порожньо (без додаткових пробілів
   обрізати не треба).
4. **`now` передається як `date`**, не `datetime`; час доби ролі не грає.

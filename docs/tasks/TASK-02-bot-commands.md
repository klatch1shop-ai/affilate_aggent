# ЗАВДАННЯ 02: текстові команди Telegram-бота — від наміру до відповіді

**Виконавець:** безкоштовна модель (`tools/llm_delegate.py`).
**Приймає:** основна модель за тестами `tests/test_bot_commands.py`.
**Дата:** 18.09.2026. **Попереднє:** ЗАВДАННЯ 01 (`ai_brain/intents.py`, прийнято).

## 1. Навіщо

`intents.parse(text)` вже розуміє, чого хоче власник. Бракує ланки
«намір → запит до маркетплейсу → зрозуміла відповідь у Telegram».
Власник 16.09: у боті немає нічого робочого, є лише **перевірені методи API**.

## 2. Головний принцип: запити до API передаються ззовні

Модуль **сам нікуди не ходить**. Функції, що звертаються до Rozetka, Нової
Пошти чи бази, передаються в `dispatch()` словником `fetchers`. Так модуль
перевіряється тестами з підробленими даними, а справжні методи під'єднує
основна модель.

## 3. Що зробити

Один файл `tg_dispatcher/ai_brain/commands.py`.

```python
COMMANDS: dict            # намір → опис команди (§3.1)
def missing_params(parsed: dict) -> list
def dispatch(parsed: dict, fetchers: dict) -> str
def fmt_orders(orders: list) -> str
def fmt_order(order: dict) -> str
def fmt_ttn(info: dict) -> str
def fmt_stock(row: dict | None, sku: str) -> str
def fmt_feeds(feeds: dict) -> str
def fmt_help() -> str
```

### 3.1. `COMMANDS`

Ключі — наміри з `intents.py`, крім `unknown`. Значення — словник:
`needs` (список обов'язкових параметрів), `fetcher` (ключ у `fetchers`),
`title` (коротка назва українською для довідки).

| намір | needs | fetcher |
|---|---|---|
| `orders_new` | `[]` | `orders_new` |
| `order_status` | `['order_id']` | `order_details` |
| `ttn_status` | `['ttn']` | `ttn_status` |
| `stock` | `['sku']` | `stock` |
| `feed_status` | `[]` | `feeds` |
| `system_status` | `[]` | `system` |
| `price_alerts` | `[]` | `price_alerts` |
| `help` | `[]` | — (`None`, відповідь без запиту) |

### 3.2. `dispatch(parsed, fetchers)` — правила

1. `parsed` — результат `intents.parse()`.
2. Намір `unknown` або `confidence < 0.5` → повернути `fmt_help()`.
3. `help` → `fmt_help()`.
4. Бракує обов'язкового параметра → повідомлення, **що саме потрібно**
   («Вкажіть номер замовлення (9 цифр)» / «номер ТТН (14 цифр)» / «артикул»).
5. Інакше викликати `fetchers[fetcher](**params)` — передаються **лише**
   параметри з `parsed['params']`, які є в `needs`, плюс `marketplace` і
   `period`, якщо вони є.
6. Відповідь форматується відповідним `fmt_*`. Для `system` і
   `price_alerts` fetcher повертає готовий рядок — віддати його як є.
7. **Будь-яка помилка fetcher'а не валить бота:** повернути рядок, що
   починається з «⚠️» і каже, яку дію не вдалося виконати. Текст винятку
   можна додати в кінці, коротко.
8. Fetcher'а немає у словнику → «⚠️ Команда ще не підключена: <title>».

### 3.3. Формати відповідей (дані — як їх повертають наші перевірені методи)

**`fmt_orders(orders)`** — список замовлень Rozetka (словники з ключами
`id`, `created`, `status`, `amount`, `purchases`: список `{'item': {'article', 'name'}, 'quantity', 'price'}`).
Порожній → «Нових замовлень немає». Інакше заголовок з кількістю і по рядку
на замовлення: номер, сума в грн, кількість позицій.

**`fmt_order(order)`** — одне замовлення: номер, статус, сума, **кожна
позиція** (артикул × кількість), ТТН, якщо є (`ttn`).

**`fmt_ttn(info)`** — статус НП: ключі `Number`, `Status`,
`WarehouseRecipient`, `ScheduledDeliveryDate` (кожен може бути відсутній).

**`fmt_stock(row, sku)`** — рядок з бази `{'sku','name','available','quantity','price_retail'}`
або `None`. `None` → «Артикул <SKU> не знайдено». `available` False або
`quantity` 0 → явно «немає в наявності».

**`fmt_feeds(feeds)`** — `{'rozetka': {'ok': True, 'age_min': 42, 'offers': 4147}, ...}`:
рядок на майданчик зі значком ✅ / ❌, віком у хвилинах і кількістю офферів.

**`fmt_help()`** — перелік команд з прикладами фраз (по одному на кожен
намір з `COMMANDS`).

## 4. Захист даних покупців

Відповіді **ніколи не містять номерів телефонів**, навіть якщо вони є у
вхідних даних (`recipient_phone`, `phone`, будь-які 10–12 цифр, що
починаються з 0 або 380). Номер замовлення (9 цифр) і ТТН (14 цифр) —
можна.

## 5. Обмеження

Тільки цей файл. Стандартна бібліотека. Python 3.13. Українською. Без мережі,
файлів, бази. HTML-розмітка Telegram дозволена (`<b>`, `<i>`), але не обов'язкова.

## 6. Приймання

`venv/bin/python -m pytest tests/test_bot_commands.py -q` — усі тести зелені.

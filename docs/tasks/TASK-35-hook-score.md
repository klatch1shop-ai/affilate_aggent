## Інтерфейс
```python
TARGET_LEN = (21.0, 34.0)          # с — цільове вікно
ALLOWED_LEN = (15.0, 45.0)         # с — допустиме
HOOK_MAX_S = 2.5
PACE = (2.5, 3.5)                  # слів за секунду
CUTS_WINDOW_S, CUTS_MIN = 5.0, 2
CTA_MAX_S, CTA_AFTER = 2.0, 0.6    # CTA не довший за 2 с і не раніше 60 % хронометражу
SIMILARITY_MAX = 0.3
GREETINGS = ('привіт', 'вітаю', 'доброго дня', 'сьогодні розповім', 'у цьому відео', 'друзі')
PROBLEM_WORDS = ('помилк', 'не роб', 'проблем', 'чому', 'скільки', 'як ', 'ризик', 'втрат')
WEIGHTS = {'hook_time': 20, 'hook_specific': 15, 'length': 15, 'no_greeting': 10,
           'pace': 10, 'cuts': 10, 'subtitles': 10, 'cta': 5, 'unique': 5}

def words(text) -> int
def shingles(text, n=4) -> set[str]
def similarity(ours, theirs, n=4) -> float
def score(video: dict) -> dict
def report(result: dict) -> str
```

`video` — `{'hook', 'timings', 'shots', 'has_subtitles', 'supplier_text'}`:
- `timings` — `[(початок, кінець, текст)]` з `voice.align`; порожній → `ValueError`;
- `shots` — `[{'duration': float, ...}]` з `plan_shots`; може бути порожнім;
- `has_subtitles` — `bool`; `supplier_text` — рядок, може бути порожнім.
- `hook` — текст гачка; якщо його нема, береться текст **першої** репліки `timings`.

### `words(text)`
Кількість слів: розбиття за пробілами, порожні відкидаються, розділові знаки не рахуються
як слова (`'Три, два — один!'` → 3).

### `shingles(text, n=4)`
Множина n-грам **слів** у нижньому регістрі, розділові знаки прибрані. Слів менше за `n` →
одна n-грама з усього тексту. Порожній текст → порожня множина.

### `similarity(ours, theirs, n=4)`
Частка шинглів `ours`, що є в `theirs` (**overlap**, не Жаккар): `len(a & b) / len(a)`.
`ours` порожній → `0.0`.

### `score(video)`
Дев'ять перевірок, кожна — `{'id', 'ok', 'weight', 'got', 'want', 'hint'}`, **у порядку `WEIGHTS`**:

| id | ok, коли | `got` | підказка при провалі |
|---|---|---|---|
| `hook_time` | перша репліка звучить `≤ HOOK_MAX_S` | тривалість, с | `'скоротіть гачок до 2.5 с'` |
| `hook_specific` | у гачку є цифра, `'?'` або слово з `PROBLEM_WORDS` | `'нема конкретики'` / `'є'` | `'додайте число, питання або проблему'` |
| `length` | сума хронометражу в `TARGET_LEN` | тривалість, с | `'цільова довжина 21–34 с'` |
| `no_greeting` | гачок не починається зі слів `GREETINGS` | знайдене привітання або `''` | `'приберіть привітання з початку'` |
| `pace` | слів за секунду в `PACE` | темп | `'темп 2.5–3.5 слова за секунду'` |
| `cuts` | у перші `CUTS_WINDOW_S` секунд починається `≥ CUTS_MIN` кадрів | кількість | `'додайте зміну кадру в перші 5 с'` |
| `subtitles` | `has_subtitles` | `True`/`False` | `'увімкніть субтитри'` |
| `cta` | остання репліка `≤ CTA_MAX_S` **і** починається після `CTA_AFTER` хронометражу | тривалість, с | `'CTA коротший за 2 с і в кінці'` |
| `unique` | `similarity(текст ролика, supplier_text) < SIMILARITY_MAX` | схожість | `'перепишіть своїми словами'` |

- `length`: у `TARGET_LEN` → повний бал; поза ним, але в `ALLOWED_LEN` → **половина ваги**
  (`ok is False`, але бал додається); поза `ALLOWED_LEN` → 0. Це єдина перевірка з півбалом.
- `supplier_text` порожній → `unique` вважається пройденою (`got = 0.0`).
- `shots` порожній → `cuts` провалена з `got = 0`.
- Повертає `{'score', 'max_score', 'checks', 'verdict', 'losses'}`:
  - `score` — сума ваг пройдених (з півбалом `length`), ціле, округлення вниз;
  - `max_score` — сума `WEIGHTS` (100);
  - `verdict`: `≥ 70` → `'публікувати'`, `50–69` → `'доопрацювати'`, `< 50` → `'не публікувати'`;
  - `losses` — `[{'id', 'weight', 'hint'}]` для непройдених, **від більшої ваги до меншої**,
    при рівній вазі — у порядку `WEIGHTS`.

### `report(result)`
```
🎬 Оцінка ролика: 75/100 — публікувати
Втрати:
• hook_time (−20): скоротіть гачок до 2.5 с
• pace (−10): темп 2.5–3.5 слова за секунду
```
- без втрат — другий рядок `'Втрат нема'` і переліку немає.

## Відповіді на можливі питання
1. **Одна репліка всього** — вона ж гачок і вона ж CTA; `cta` перевіряється за тими самими
   правилами (майже напевно провалиться — це нормально й чесно).
2. **Числа в гачку** — будь-яка цифра, зокрема у слові `19-в-1`.
3. **Регістр і апостроф** у `GREETINGS`/`PROBLEM_WORDS` — порівняння в нижньому регістрі,
   апостроф `’` = `'`.
4. **Чому overlap, а не Жаккар** — нас цікавить, скільки **нашого** тексту списано, а не
   взаємна схожість; довгий опис постачальника не має розмивати показник.

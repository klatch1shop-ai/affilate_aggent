## Інтерфейс
```python
WINDOWS = (30, 90)                      # дні
KNOWN_GAPS = ('покази й кліки на маркетплейсі', 'перегляди й переходи із соцмереж')

def build(sku, *, orders, returns, questions, reviews, prices, our_price, now) -> dict
def report(funnel: dict) -> str
```

Вхідні форми (зайві ключі ігнорувати):
- `orders`: `{'id', 'created' (datetime), 'status' ('done'|'cancelled'|'processing'), 'sum' (число)}`
- `returns`: `{'order_id', 'created', 'reason'}`
- `questions`: `{'id', 'created', 'answered' (bool)}`
- `reviews`: `{'id', 'created', 'rating' (1–5)}`
- `prices`: `{'seller', 'price'}` — ціни конкурентів
- `our_price`: число або `None`

### `build`
Повертає словник із ключами:
- `sku`;
- `orders_30`, `orders_90` — кількість замовлень у вікні (`created >= now - N днів`);
- `sum_30` — сума `sum` замовлень зі `status == 'done'` за 30 днів, округлена до 2 знаків;
- `buyout` — частка `done` серед `done + cancelled` за 90 днів, округлена до 2 знаків;
  знаменник 0 → `None` (**не 0.0**: це різні речі — «не викуповують» і «даних нема»);
- `returns_30` — кількість повернень за 30 днів;
- `questions_open` — кількість питань із `answered is False` (без обмеження за часом);
- `reviews_count`, `rating` — кількість відгуків і середня оцінка за 90 днів (округлення 2 знаки),
  відгуків нема → `reviews_count = 0`, `rating = None`;
- `our_price`, `min_price` (мінімальна серед `prices`), `min_seller` (продавець із нею;
  при однаковій ціні — перший у списку);
- `price_gap` — на скільки відсотків наша ціна вища за `min_price`, округлення 1 знак;
  від'ємне значення означає, що ми дешевші; `None`, якщо нема `our_price` або `prices`;
- `gaps` — список рядків: усі `KNOWN_GAPS` **завжди**, плюс `'немає цін конкурентів'`
  (порожній `prices`), `'немає відгуків'` (`reviews_count == 0`), `'немає замовлень за 90 днів'`
  (`orders_90 == 0`) — саме в такому порядку.

### `report(funnel)`
```
📊 SO3142
Замовлення: 4 за 30 дн · 9 за 90 дн · виконано на 1 250.00 ₴
Викуп: 78% · повернень за 30 дн: 1
Питання без відповіді: 2
Відгуки: 5 · середня 4.60
Ціна: 149.00 ₴ · найдешевший конкурент 132.00 ₴ (Продавець) · ми дорожчі на 12.9%
Чого не знаємо: покази й кліки на маркетплейсі; перегляди й переходи із соцмереж
```
- `buyout is None` → `'Викуп: даних нема'`; частка друкується цілими відсотками (`round`).
- `rating is None` → `'Відгуки: 0'` без середньої.
- Нема `our_price` або `prices` → рядок `'Ціна: …'` містить лише те, що відоме;
  зовсім нічого — рядок не виводиться.
- `price_gap < 0` → `'ми дешевші на X%'`; `0` → `'ціна однакова'`.
- Суми — з пробілом між тисячами й двома знаками (`1 250.00`).
- Останній рядок — `'Чого не знаємо: '` і `gaps` через `'; '`.

## Відповіді на можливі питання
1. **`status == 'processing'`** — рахується в `orders_30/90`, але не в `sum_30` і не у `buyout`.
2. **Замовлення без `sum`** — вважається `0` у сумі, у кількості рахується.
3. **`now` — `datetime` з UTC**; межа вікна включна (`created >= now - timedelta(days=N)`).
4. **Повернення й питання прив'язані до цього ж SKU** — фільтрувати за SKU не треба,
   викликач передає вже відібране.

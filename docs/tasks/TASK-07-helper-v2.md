## 3. `InboxStore.unanswered(now, older_than_min, max_age_min=None)`

Новий необов'язковий параметр. Якщо задано — не повертати чати, що чекають **довше** за
`max_age_min` хвилин (`waiting_min > max_age_min` → відкинути). `None` — як зараз.

## 4. `commands.fmt_order(order)` — стан посилки

Якщо в `order` є ключ `ttn_info` (словник), після рядка `ТТН: …` додати:
- якщо в `ttn_info` є `error` → рядок `Посилка: ⚠️ <error>`;
- інакше, для кожного наявного непорожнього поля по черзі:
  `Status` → `Посилка: <Status>`, `WarehouseRecipient` → `Відділення: <…>`,
  `ScheduledDeliveryDate` → `Очікується: <…>`.
Без `ttn_info` — вивід **точно як зараз**. Маскування телефонів (`_safe`) — як і було.

## 5. `helper/services.build_fetchers` — збагачене замовлення

Якщо передано **і** `rozetka`, **і** `novaposhta`, `order_details` робить:
`order = rozetka.order(order_id)`; якщо `order['ttn']` після видалення пробілів — рівно
14 цифр → `order['ttn_info'] = novaposhta.ttn_status(ttn)`; `ApiError` або `ValueError` з
`ttn_status` → `order['ttn_info'] = {'error': str(e)}` (**замовлення все одно
показується**). ТТН нема чи не 14 цифр → `ttn_info` не додається. Лише `rozetka` без
`novaposhta` — як зараз. Словник, який повернув `rozetka.order`, не мутувати — копія.

## 6. `helper/keyboards.py`

```python
MENU: list[list[str]]          # рядки кнопок
BUTTONS: dict[str, str]        # текст кнопки → фраза для intents.parse
def to_query(text: str) -> str
```
- `MENU` — рівно 2 рядки по 2 кнопки: `['🆕 Нові замовлення', '📦 Стан фідів']`,
  `['🖥 Статус системи', '❓ Довідка']`.
- `BUTTONS` містить **усі** кнопки з `MENU` і лише їх; фраза кожної кнопки має
  розпізнаватись `intents.parse` відповідно як `orders_new`, `feed_status`,
  `system_status`, `help` з `confidence >= 0.5`.
- `to_query(text)` — кнопка (після `strip()`) → її фраза; будь-який інший текст —
  без змін.

## 7. `helper/digest.py`

```python
KYIV = zoneinfo.ZoneInfo('Europe/Kyiv')
def due(now: datetime, last_sent: date | None, hour: int = 9) -> bool
def build_digest(now: datetime, orders, unanswered, feeds, services) -> str
```

### 7.1. `due`
`True`, якщо за київським часом `now` уже `>= hour:00` **і** `last_sent` не дорівнює
сьогоднішній київській даті. `now` без зони → `ValueError`.

### 7.2. `build_digest`
Кожен з аргументів `orders` (список замовлень як з `clean_order`), `unanswered`
(список з `unanswered()`), `feeds` (результат `feeds_status`), `services`
(`{назва: стан}`) може бути `None` — **не вдалося отримати**; це має бути видно, а не
ховатись як «нічого нема».

Рядки по черзі:
1. `☀️ Ранковий звіт DD.MM` (київська дата `now`).
2. Замовлення: `None` → `⚠️ Замовлення: не вдалося отримати`; порожній список →
   `🆕 Замовлень у роботі: 0`; інакше `🆕 Замовлень у роботі: N`, далі до 10 рядків
   `№<id> — <amount> грн`, і якщо їх більше — рядок `… ще K`.
3. Чати: `None` → `⚠️ Чати покупців: не вдалося отримати`; порожньо →
   `💬 Чати без відповіді: 0`; інакше `💬 Чати без відповіді: N`, далі по рядку на чат:
   `<мітка майданчика з inbox.render.LABELS> · чат <id>: <waiting_min> хв`.
4. Фіди: `None` → `⚠️ Фіди: не вдалося отримати`; усі `ok` → `📦 Фіди: усі в нормі`;
   інакше `📦 Фіди з проблемами:` і рядок на кожен не-`ok`:
   `❌ <назва>: вік <age_min або —> хв; офферів: <offers>`.
5. Служби: `None` → `⚠️ Служби: не вдалося отримати`; усі `'active'` →
   `🖥 Служби: усі працюють`; інакше `🖥 Служби з проблемами:` і `❌ <назва>: <стан>`.
Увесь текст — через `tg_dispatcher.privacy.mask_private`. Звичайний текст, без HTML.

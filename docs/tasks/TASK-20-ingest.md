## Інтерфейс
```python
VAULT = 'wiki'
def slugify(title: str) -> str
def parse_report(text: str) -> dict
def wikify(text: str, known) -> str
def build_note(report: dict, *, source: str, known=()) -> dict
def log_line(note: dict) -> str
def plan(notes: list[dict], existing: dict) -> dict
```

### `slugify(title)`
Нижній регістр; пробіли й `_` → `-`; лишаються лише літери (зокрема кирилиця), цифри й `-`;
кілька `-` підряд → один; `-` по краях обрізаються; далі обрізати до 60 символів **і ще раз**
прибрати `-` по краях.
Порожній результат → `ValueError`.

### `parse_report(text)`
Розбирає наш звичний markdown-звіт. Повертає `{'title', 'date', 'sections'}`:
- `title` — перший рядок, що починається з `'# '` (без решітки й пробілів). Немає → `ValueError`.
- `date` — з рядка виду `**Дата:** 20.09.2026` → рядок `'2026-09-20'`. Немає або не та форма → `None`.
- `sections` — `[{'heading', 'body'}]` по рядках `'## '`; `body` — текст до наступного `'## '`,
  обрізаний по краях. Текст до першого `'## '` — секція з `heading == 'Вступ'`, якщо після
  викидання рядка заголовка `'# '` **і рядка з `**Дата:**`** лишається непорожній текст.

### `wikify(text, known)`
`known` — назви сутностей (товар, майданчик, постачальник, поняття). Кожну **першу** появу в тексті
обгортає у `[[назва]]`.
- пошук без урахування регістру, але у тексті лишається **написання з тексту**:
  `'розетка'` при `known=['Rozetka']` не чіпається (різні рядки), а `'Rozetka'` → `[[Rozetka]]`;
  збіг шукається за точним рядком без урахування регістру.
- збіг лише по межах слова: `'Прометей'` при `known=['Prom']` не чіпається;
- довші назви мають пріоритет (`'Нова Пошта'` перед `'Пошта'`);
- що вже всередині `[[...]]` — вдруге не обгортається;
- `known` порожній → текст без змін.

### `build_note(report, *, source, known=())`
Повертає `{'path', 'content', 'title', 'date'}`:
- `path` — `f'{VAULT}/{slugify(title)}.md'`;
- `content` — заголовок YAML і тіло:
```
---
title: <title>
date: <date або порожньо>
source: <source>
---

## <heading 1>
<body 1>

## <heading 2>
<body 2>
```
- тіло проходить `mask_private` **і** `wikify` (спершу маскування, потім `wikify`);
- `content` закінчується одним `\n`.

### `log_line(note)`
`'- [[<slug>]] — <title> (<date>)'`; без дати — `'- [[<slug>]] — <title>'`.

### `plan(notes, existing)`
`existing` — `{шлях: вміст}` уже наявних нотаток. Повертає
`{'create': [...], 'skip': [...], 'conflict': [...]}`:
- шляху немає в `existing` → `create` (нотатка цілком);
- є і вміст **однаковий** → `skip` (лише шлях);
- є і вміст інший → `conflict` (лише шлях) — **чуже не перезаписуємо**;
- дублі шляхів усередині `notes`: друга й наступні → `conflict`.

## Відповіді на можливі питання
1. **Заголовок із двокрапкою** (`# ЗАВДАННЯ 31: перевірка`) — двокрапка в `slugify` зникає як
   будь-яка пунктуація; у `title` і в YAML лишається як є (значення YAML **брати в лапки**,
   якщо містить `:` — інакше файл не читається Obsidian).
2. **`known` містить порожній рядок** — пропускається.
3. **Немає секцій** — тіло після YAML порожнє, `content` усе одно валідний.
4. **Маскування** — лише через `mask_private`; власних правил не вигадувати.

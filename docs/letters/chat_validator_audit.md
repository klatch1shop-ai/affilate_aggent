## Метод пошуку

Шукав чотири відомі підписи класу, кожна з яких уже колись нас підвела:

```
A  регекс із лімітом довжини        ← SELLER {1,60}, обірвана пагінація
B  \w там, де є непробільна пунктуація ← &\w+; не ловив &#39;
C  евристика за закінченням слова    ← _is_adj
D  підрядок там, де мав бути токен   ← DESC_NOUNS in pair
```

A і B у поточному коді більше не трапляються. C і D дали три влучення.

## ДЕФЕКТ 5 — `head_noun()`: підтвердження типу за п'ятьма літерами

Файл `tools/prom_kw_matrix.py`. Це джерело **типу Р** із семантичного звіту.

```python
if v.split()[-1][:5] in nm:            # «слово типу справді є в назві»
    return v
```

Докстрінг обіцяє: «Тип із характеристик беремо лише тоді, коли він
**підтверджується назвою**». Насправді перевіряється **п'ятилітерний префікс
останнього слова, підрядком**. Перевірено виконанням:

```
назва : Силіконова анальна пробка Mystim Rocking Vibe з вібрацією
тип   : «класичний вібратор» → перевірено лише «вібра»
        «вібра» знайдено в слові «вібрацією» → ПРИЙНЯТО
        пробка отримала дев'ять ключів навколо слова «вібратор»

назва : Мастурбатор-ротик Kiiroo Feel Mouth
тип   : «вагінальний мастурбатор» → перевірено лише «масту»
        ПРИЙНЯТО → ротик отримав ключі «вагінальний», «штучна вагіна»

назва : Ерекційне кільце з віброкулею Bathmate Maximus VIBE
тип   : «віброкулі» → перевірено «вібро» → ПРИЙНЯТО
        кільце отримало всі дев'ять ключів про віброкулі
```

**І головне: означення не перевіряється взагалі.** У типі «класичний
вібратор» звіряється лише «вібра». Слово «класичний» не перевіряє ніхто —
тому кліторальний вібратор і стає «класичним».

### Масштаб

```
товарів усього                                   5386
тип узято з характеристики (префікс збігся)      1870
   з них СЛАБКЕ підтвердження — цілого слова
   в назві немає                                  389  (20.8 %)
двослівних типів у характеристиках               1373  ← означення
                                                        не перевіряється
                                                        в жодному з них
```

Приклад, який пояснює SO7497 із семантичного звіту:
`AD30604` — товар «Ерекційне кільце Devol Cockring із вібрацією», тип із
характеристики «класичний вібратор», підтверджено словом «вібрацією».

## ДЕФЕКТ 6 — `word_gender()`: середній рід множини читається як жіночий

Файл `tools/prom_keywords.py`, рядки 204-208.

```python
if w.endswith(('и', 'і', 'а́', 'ї')) and not w.endswith(('ка', 'ля')):
    return 'p'
if w.endswith(('а', 'я')):
    return 'f'
```

Закінчення `я` перевіряється **після** перевірки на множину, а в тій
множинній тюплі `я` немає. Тому:

```
віброяйця  → 'f' (жіночий однини)   ✗  насправді середній множини
віброкулі  → 'p' ✓
ділдо      → 'n' ✓
трусики    → 'p' ✓
```

Звідси «силіконов**а** віброяйця» і «водонепроникн**а** віброяйця» з вибірки.

Механізм для множини існує й працює — `GENDER_IDX` містить `'p': 3`. Ламається
саме класифікатор, не узгоджувач.

## ДЕФЕКТ 7 — `agree()` викликається не скрізь

Це рівно те, що ви передбачили: **не нова логіка, а прогалина покриття.**

`agree()` викликається у **6 місцях** із 24 шаблонів, що клеять слова:

```
рядки 408, 410, 413, 423, 554, 557   → agree() є ✓
рядки 466, 528  tpl.format(n=noun)   → agree() НЕМАЄ ✗
рядок 387       f'{ph} {noun}'       → agree() НЕМАЄ ✗
```

Шаблони `FEATURE` і `FUNCTIONAL` містять прикметники, **зашиті в чоловічому
роді**:

```
анальний · безшумний · вагінальний · водонепроникний · гіпоалергенний
класичний · охолоджувальний · подарунковий · подвійний · розігрівальний
смарт · їстівний
```

Вони приклеюються до будь-якого іменника як є.

### Масштаб

```
карток із неузгодженим прикметником : 317  (5.9 %)
таких фраз                          : 360  (0.95 %)

вагінальний віброкулі · безшумний вагінальні кульки · вагінальний віброяйця
гіпоалергенний насадка член · їстівний масажна піна · розігрівальний масажна олія
водонепроникний вібратор-насадка на палець
```

**Застереження до цього числа.** Перший мій детектор дав 454 картки — і був
неправильний: він звіряв рід **останнього** слова фрази, через що
«класичний вібратор для клітора» позначалась як помилка, хоча вона коректна.
Виправив на «іменник одразу після прикметника», отримав 317. Наводжу обидва
числа, щоб було видно, що детектор теж перевірявся.

## Зведення: сім дефектів, один клас


**Спільна ознака всіх семи:** функція **повертає значення** й ніколи не кидає
винятку. Тест на неї зелений, бо результат є. Помилковий, але є.

## Що це означає для інструменту перевірки

Ваш поділ на три рівні довіри правильний, і аудит його підтверджує:
`head_noun()` виглядає як детерміноване правило (Рівень 1), а насправді це

**Пропоную додати до Рівня 1 ще одну перевірку**, якої у вашому переліку
немає, бо вона стала очевидною тільки після цього аудиту:

```

```

Це детерміновано, не потребує морфології, і ловить дефект 5 на виході, навіть
поки він не виправлений на вході.

## Чого я НЕ робив

Жодної правки. Три дефекти знайдені й виміряні, але `head_noun()`,
`word_gender()` і шаблони не чіпав.

Причина та сама, що й минулого разу: `head_noun()` зачіпає **1870 карток**,
де тип узято з характеристики. Виправлення «перевіряти ціле слово» відкине
389 із них — і я не знаю, скільки з цих 389 насправді коректні. Це рівно
ситуація `_is_adj`, де повне вимкнення забрало 27 % корисного.

Перед правкою потрібна калібрувальна вибірка **на нових картках**, не на тих
49, що вже переглянуті — вони забруднені.

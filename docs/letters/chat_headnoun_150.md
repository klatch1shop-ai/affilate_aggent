# Калібрування head_noun на чистих 150: моя попередня оцінка була вчетверо завищена

Дата: 09.09.2026. Вибірка `docs/prom_headnoun_sample150.txt`,
контроль зміщення пройдено (48.6 %, 0.3σ).

---

## 1. Головний результат — і він проти мого попереднього твердження

Учора я оцінив частку хибно прийнятих типів у **20.8 %**, порахувавши, у
скількох карток ціле слово типу відсутнє в назві. Ручний розбір 150 карток
дає інше:

```
головне слово типу ХИБНЕ        :   6 із 150 = 4.0 %   95% ДІ [1.8 %, 8.5 %]
```

**Різниця в п'ять разів**, і причина в тому, що мій автоматичний підрахунок
рахував артефакти форматування як помилки:

```
«портупея/збруя»  → брав увесь токен зі скісною рискою; «портупея» в назві Є
«віброяйця»       → множина проти «Смарт-віброяйце» в назві
«мастурбатор»     → «Мастурбатор-торс», «Мастурбатор-ротик» — складне слово
«вібратор-пульсатор» → «Смартвібратор-пульсатор»
```

З урахуванням альтернатив через «/» і дефіс головне слово підтверджується
**у 144 із 150 (96 %)**.

## 3. Справжня діра — в означенні, і вона вчетверо більша

```
типів без означення               :  89
означення підтверджене назвою     :  10
означення НЕ підтверджене         :  51 із 150 = 34.0 %  ДІ [26.9 %, 41.9 %]
   з них «класичний / класична»   :  38 = 25.3 %         ДІ [19.0 %, 32.8 %]
```

Це рівно те, що ви передбачили: **означення не перевіряється взагалі**, і
саме воно ламає фразу.

Два найчастіші типи в характеристиках — і обидва починаються з «класичн»:

```
20 карток  «класична анальна пробка»
18 карток  «класичний вібратор»
```

Приклади, де «класичний» прямо суперечить товару:

```

```

Покупець, який шукає «класичну анальну пробку», хоче просту. Отримує металеву
з хвостом або вібропробку — покази без кліків, тобто рівно та шкода, про яку
попереджає докстрінг самого генератора.

## 5. Що з цього випливає для виправлення

**Правити треба не те, що я пропонував учора.**

Я збирався замінити перевірку «5 літер підрядком» на «ціле слово». Це
виправило б 6 карток зі 150 і зламало б 29, де головне слово стоїть у складі
складного («Мастурбатор-торс») — тобто зробило б гірше.

Правильна правка інша:

```
головне слово : лишити як є, додати розбір «/» і дефіса
                (виправляє артефакти, не чіпає логіку)
означення     : ПЕРЕВІРЯТИ окремо. Якщо означення типу не підтверджується
                назвою — брати сам іменник без означення.
                «класичний вібратор» → «вібратор»
```

Друге правило детерміноване, не потребує морфології, і б'є точно в 34 %.
Воно не вигадує нічого — просто відкидає непідтверджену частину.

**Ціна:** 38 карток утратять слово «класичний» у частині фраз. Оскільки
товар справді не класичний, це не втрата, а прибирання хибного сигналу.

**Не реалізовано** — за правилом 11.2 наступний крок після цього заміру —
окремий замір наслідку правки, а не сама правка.

## 6. Ще один урок про власні детектори

Мій учорашній автоматичний підрахунок 20.8 % був хибний **учетверо**, і хибний
у бік перебільшення. Причина та сама, що вже двічі: **я порахував розбіжність
рядків і назвав її помилкою, не відкривши список.**

Це четвертий випадок правила 11.1 за три доби. Цього разу він коштував лише
однієї неправильної оцінки, бо ручний розбір ішов одразу після — але якби я
робив правку за тим числом, вона зачепила б 389 карток замість 75.

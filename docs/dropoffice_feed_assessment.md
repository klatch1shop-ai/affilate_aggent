## 3. Що доведеться робити

### 3.1. Артикул лежить у характеристиці, а не в тегу

```
тег <article> / <vendorCode> : 0 із 1207
<param name="Артикул">       : 1207 із 1207   ← SW-00000350
```

Розетка вимагає артикул окремим полем. Витяг тривіальний, але без нього фід
не пройде.

### 3.2. Дубльована країна виробника

```
«Країна виробник»             1141   українською
«Страна-производитель товара» 1141   російською, ті самі значення
```

Треба обрати одну — інакше Розетка побачить суперечливі характеристики.

### 3.3. Мапа категорій — найдорожче

80 категорій постачальника треба зіставити з деревом Розетки. Це та сама
робота, що для TOPTUL, і там вона була найдовшою. Категорії конкретні
(«PET плитка 600*300», «Рейки PS 2900*120мм»), тож зіставлення здебільшого
однозначне, але виконувати його доведеться вручну.

## 4. Перевірка за критеріями, на яких завалився TOPTUL

### Описи — чисті

```
посилання, телефони, назва компанії, гарантія,
пропозиції іншого товару, емодзі          : 0 із 1207
```

Дві «знахідки» перевірено в контексті й **обидві хибні**:

```
«доставка» 64 картки → «Можливість доставки плити у важкодоступні місця
                        ЗАВДЯКИ ЇЇ ЛЕГКОСТІ» — про товар, не про умови
«ціна»    138 карток → «ціна за 1 шт. (СПП-500)» у заголовку опису —
                        одиниця продажу, не прайс
```

**Чистильник TOPTUL тут застосовувати не можна** — він вирізав би 64 коректні
речення. Якщо Розетка причепиться до «ціна за 1 шт.», прибирати треба
прицільно цю конструкцію, а не все зі словом «ціна».

### Фото — тут ризик, і він реальний

Переглянув вибірку вручну. Перше фото картки — чистий предметний або
інтер'єрний знімок 1200×1200, без рамок і вотермарок. **Але серед решти є
інфографіка:** підписи «1. Верхній пігментований ПВХ шар», «2. Армуюча
сітка», кругові врізки-збільшення, кольорова панель із текстом.

Це рівно те, за що Розетка відхилила TOPTUL: «написи не про товари, ярлики,
вотермарки, рамки та інші графічні елементи».

**Автоматично відрізнити інфографіку від фото я не вмію** — сьогодні перевірив
це прямо: детектор рамки не впізнав навіть те зображення, яке Розетка сама
показала як приклад. Варіанти:

```
а) брати лише ПЕРШІ N фото картки     дешево, але N вгадується
б) ручний перегляд                     7947 зображень — нереально
в) модель із зором                     треба перевіряти на контрольній вибірці
```

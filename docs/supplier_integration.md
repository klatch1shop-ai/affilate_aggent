# Інструкція для постачальника Carvol

## Схема взаємодії

```
klatch1.shop                          Carvol
    │                                    │
    │  1. Замовлення з Розетки            │
    │     ↓                              │
    │  2. Excel-бланк у Telegram  ───────►│
    │                                    │  3. Відправляє замовлення
    │                                    │     клієнту через Нову Пошту
    │  4. PDF накладної НП        ◄───────│
    │     ↓                              │
    │  5. ТТН автоматично                │
    │     встановлюється в Розетці       │
```

Весь обмін відбувається через Telegram.


## Що отримує постачальник

Після кожного нового замовлення у Telegram надходить **Excel-файл** із заявкою.

### Поля в Excel-бланку

| Поле | Що означає |
|------|------------|
| Перевізник | Нова Пошта (завжди) |
| Оплата | Тип оплати та сума до стягнення з клієнта |
| Коментар | ПІБ отримувача, телефон, місто та відділення НП |
| Замовлення | Номер замовлення Розетки та дата |
| Код клієнта | Наш ідентифікатор у системі Carvol (якщо є) |
| № | Порядковий номер позиції |
| Артикул | Артикул товару з каталогу |
| Найменування | Назва товару |
| Кількість | Кількість одиниць |

### Типи оплати

- **Накладений платіж** — кошти стягуються з клієнта при отриманні посилки.
- **Передоплата** — клієнт уже оплатив, відправляти без стягнення.


## Що надсилає постачальник

Після відправки замовлення — **PDF-файл накладної Нової Пошти** у той самий Telegram-чат.

### Вимоги до PDF

- Стандартна накладна Нової Пошти (формат, який видає кабінет НП або застосунок).
- Файл має містити номер ТТН (наприклад: `20 4514 5092 1650`).
- Один файл = одна накладна. Якщо кілька замовлень — надсилати окремими файлами.

Після отримання PDF система автоматично зчитує ТТН і прив'язує його до замовлення в Розетці. Нічого додатково робити не потрібно.


## Покроковий процес

### Крок 1 — Отримати заявку
У Telegram надійде Excel-файл із заявкою на відправку. Файл містить усі дані отримувача та перелік товарів.

### Крок 2 — Відправити замовлення
Зібрати та відправити замовлення клієнту через Нову Пошту, вказавши:
- отримувача та відділення з Excel-бланку;
- суму накладеного платежу (якщо тип оплати — накладений платіж).

### Крок 3 — Надіслати PDF накладної
Після створення накладної в кабінеті Нової Пошти — надіслати PDF-файл у той самий Telegram-чат, звідки прийшов Excel.

Більше нічого не потрібно — ТТН з'явиться в Розетці автоматично.

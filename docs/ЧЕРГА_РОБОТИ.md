# Черга роботи (підхоплювати на початку сесії)

Оновлено: 2026-10-14, після автопривʼязки постачальника.

Мене не запускає cron: у системі немає CLI `claude`, я живу лише в
сесії VSCode, яку відкриває власник. Тому цей файл — точка входу:
прочитати його першим і продовжити з верху списку.

Автоматика від мене не залежить. Поки сесії немає, на сервері далі
працюють 21 запис cron і служби (фіди, агенти замовлень, сторож,
helper-bot). Стоїть лише те, що вимагає мого рішення.

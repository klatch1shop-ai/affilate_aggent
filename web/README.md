# web/ — презентаційна панель (PWA)

Статична сторінка з лівою вертикальною панеллю і вісьмома розділами.
Жодне число не вписане в розмітку: усе малюється з `data.json` і
`commands.json`, інакше сторінка тихо розійдеться з дійсністю.

```
index.html   оболонка й розділи
app.css      дизайн-система (токени, теми, сітка)
app.js       маршрутизація по хешу + малювання сторінок
data.json    факти з аудиту — правити ТУТ, не в розмітці
commands.json довідник команд, ГЕНЕРУЄТЬСЯ з helper/supervisor.py
sw.js        офлайн-оболонка; піднімати V при зміні файлів
```

## Як оновити довідник команд
Він збирається з коду, щоб не розійтись із ним, і кожна фраза
проганяється через `parse()` — у файл потрапляють лише ті, що справді
розпізнаються:

```bash
venv/bin/python tools/web_commands_build.py
```

## Дизайн
Напрям — редакційно-індустріальний: серифні заголовки вагою 400 на
технічному сансі, тепле паперове тло, один теплий акцент.

Референс ніші — **Mirakl** (лідер marketplace SaaS; за обсягом з боку
продавця більший Rithum, але в нього немає витягуваної дизайн-системи).
Узято чотири прийоми: серифний заголовок вагою 400, числа як чиста
типографіка без карток, картка через бордюр а не тінь, mesh-градієнт у
hero з розчиненням у фон. Палітра своя — чужу не копіював.

## Жива частина (panel/)

`panel/server.py` — FastAPI на адресі Tailscale ноутбука
`http://100.126.131.55:8600`. Служба `systemd --user`:

```bash
systemctl --user status panel      # стан
systemctl --user restart panel     # перезапуск
journalctl --user -u panel -n 30   # журнал
```

Назовні не видно (перевірено). Доступ — cookie `SameSite=Strict`, яку
видає корінь сторінки; запит із чужим Origin відхиляється.

### Правило, яке не можна змінювати мовчки
**Панель пропонує, але не підтверджує.** R0 виконується одразу; R2 і R3
йдуть у Telegram як прохання. Причина — `confirm.db` один, і захист від
подвійної накладної діє лише в межах однієї бази. Деталі:
[рішення 002](../docs/рішення/002-жива-панель.md).

### Мій бік дошки
```bash
venv/bin/python tools/panel.py нове              # що власник додав
venv/bin/python tools/panel.py відповісти "..."  # відповідь у чат + Telegram
venv/bin/python tools/panel.py завдання "назва"  # додати від себе
venv/bin/python tools/panel.py стан 3 "зроблено"
```
